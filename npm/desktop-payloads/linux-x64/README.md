# @xulongzhe/clawbench-desktop-linux-x64-payload

**Internal package — do not install.** This is the incremental-upgrade payload (application files only, no Electron runtime) for the [ClawBench](https://github.com/clawbench-dev/clawbench) desktop client on Linux x64.

It is downloaded by the ClawBench desktop app itself during an in-app update, and is only valid against a matching Electron shell version. The installable desktop app is distributed as a full package on [GitHub Releases](https://github.com/clawbench-dev/clawbench/releases).
