# 中文路径图片测试

这个文件用来验证一件事：**图片地址里带中文时，预览页和分享页都要能显示出来。**

文档自己所在的目录带不带中文**不影响**结果，只有**图片地址**带中文才会踩到坑。

## 病根（一句话）

`marked` 会把图片地址里的中文编成 `%E5%9B%BE…` 写进网页；分享页拼链接时把这段又当成
路径原文编了一遍，成了 `%25E5%259B%25BE…`。后端照着去磁盘找，找一个名字字面叫
`%E5%9B%BE…` 的文件，找不到，于是 404。

修法是"先还原再编"，不是"少编一次"。

## 怎么验

1. 在文件管理器里打开本文件，切到**渲染**视图 —— 下面三张图都要出来。
2. 对这个文件**创建分享链接**，用无痕窗口打开分享页 —— 下面三张图同样要出来。
3. 打不开时看 Network：失败的图片请求如果长这样
   `...?path=%2F...%2F%25E5%259B%25BE...` （`%25` 就是被编了两次的痕迹），
   说明前端是旧版本。分享页是**服务器**下发的，服务器不升级就还是坏的。
