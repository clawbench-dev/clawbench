这一段普通文字放在最前面，用来确认表格上方的间距正常（不该多出一条空白）。

## 全数值表 → 应该是数据表

除了表头和第一列，每一格都是数字。打开后应当看到：

- 表格上方的「普通表 / 数据表」切换条
- 搜索框、「筛选行」「列」按钮
- 表头右侧的漏斗（点开是这一列的筛选、排序、统计）
- 数字右对齐、背后有数据条、底部有合计行

## 全是文字 → 简单表

没有任何一列是纯数字，默认就是简单表：只有表头栏和表，不露工具条。

| 参数 | 说明 |
| --- | --- |
| 超时 | 请求超过这个时间就断开 |
| 重试 | 失败后自动重试的次数 |
| 并发 | 同时处理的请求数 |

## 切换验证

上面两张表都能在表头栏上切「简单表 / 数据表」：简单表没有工具条、没有合计行；数据表才有搜索、筛选行、列，数字列还会右对齐、画数据条、加合计。
