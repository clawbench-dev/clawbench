XMB 波浪壁纸

清晰波形 · 波内渐变 · 仅 3 条 · 整页约半个周期
你
波浪应该是很清晰的一个波浪，背景色有点渐变色，波浪里面也有点渐变色，但是波浪是一条很清晰的波浪。同时出现的波浪大概就两三条。
AI
上一版用 5 层厚度递减叠出"柔光"，把边缘糊掉了 —— 方向错了。现在改成 实心填充 + 明确波峰边缘：波形是清晰的，边缘靠"渐变在波峰处突亮"做出来， 而不是靠模糊。
底 竖直渐变（上暗 → 下亮），很淡 波 从曲线向下填充，内部竖直渐变： 波峰处最亮 → 向下渐隐 边 波峰 1.5px 高亮描边 // 清晰度的关键 层 3 条，base = 0.34 / 0.55 / 0.76 λ ≈ 2.4 页宽 → 整页约 0.42 个周期
