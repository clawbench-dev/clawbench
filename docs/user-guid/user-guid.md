# 第一部分：快速上手

## 1. 登录

打开 ClawBench 的第一步：输入访问密码，验证身份后进入工作台。

浏览器打开你的 ClawBench 地址（默认 `https://<主机>:20000`），输入访问密码即可。

![登录页](screenshots/01-login.png)

页面构成：

- **品牌区**：Logo、产品名、标语「从掌心到桌面」、副标题「多端一体的 AI 工作台」
- **密码输入框**：服务端设置的访问密码
- **「登录」按钮**：提交后写入登录 Cookie
- **多服务器列表**（仅 Android App 模式且已保存 ≥2 个服务器时出现）：可在多个已保存的服务器之间切换，或删除某个服务器

密码在服务端配置文件 `~/.clawbench/config/config.yaml` 的 `password` 字段，由部署者设置。登录态通过 Cookie 保持；若你使用多个 ClawBench 实例，各实例登录态互相隔离，可同时登录。

> **提示**：服务端默认使用 HTTPS。若浏览器提示证书不受信任（自签证书），首次访问时手动信任即可。

## 2. 选择项目

项目就是服务器上的一个目录，切换项目等于切换整套工作环境（会话、任务、Git、文件都跟着变）。

ClawBench 的一切操作都围绕「项目」展开——项目就是服务器上的一个目录。点击顶栏的项目名称可切换或新增项目。

- 每个项目独立维护自己的**会话列表、任务、Git 状态、文件树**。
- 切换项目时，当前项目的聊天输入草稿会被保留，切回来时自动恢复。
- 项目路径必须位于服务器可访问的文件系统内。不在列表里的目录可通过「打开目录」手动指定路径添加。
- 最近打开的项目会出现在项目下拉面板中，可单独移除。

## 3. 界面总览

介绍宽屏下的三栏布局：左侧功能栏、中间聊天区、右侧会话列表。

桌面宽屏（视口宽度 ≥ 1024px）下，界面自动切换为**三栏布局**：

![聊天总览](screenshots/03-chat-overview.png)

| 区域 | 作用 |
|---|---|
| **最左侧竖向图标栏**（Dock） | 切换左侧面板；最底部是「隐藏/显示聊天区域」开关 |
| **左侧内容区** | 当前选中的面板内容（默认是文件管理器） |
| **中间聊天区** | 与 AI 的对话；这是你花时间最多的地方 |
| **右侧会话侧栏** | 当前项目的会话列表（固定 280px 宽） |

Dock 的九个页签，从上到下：

| 图标位置 | 页签 | 作用 |
|---|---|---|
| 1 | **文件管理器** | 浏览/操作项目文件（默认打开） |
| 2 | **文件** | 文件查看器（双击文件后在此打开） |
| 3 | **项目历史** | Git 提交历史、分支、标签、工作树 |
| 4 | **议题与合并请求** | GitHub/GitLab 集成（Forge） |
| 5 | **任务** | 定时任务与事件任务 |
| 6 | **终端** | Web 终端 |
| 7 | **数据统计** | 用量统计、代码存量、代码增量 |
| 8 | **端口映射** | SSH 隧道端口转发 |
| 9 | **设置** | 全部配置项 |
| 底部 | **隐藏/显示聊天区域** | 把聊天区折叠，左栏占满宽度 |

**调整左右分栏宽度**：把鼠标移到左侧内容区与聊天区之间的分隔条上，光标变为左右箭头后拖动即可。比例会被记住。

> **提示**：Dock 页签的角标会提示待处理事项（如 Git 有未提交变更、Forge 有未读动态、任务有未读执行）。点击**已激活**的页签会折叠左栏（VS Code 行为），再点一次恢复。

窄屏（窗口宽度 < 1024px）下，三栏收成单栏，Dock 变成底部标签栏。

## 4. 发起第一次对话

从零开始：新建会话、选智能体、输入需求、看 AI 流式回复。

1. 点击会话侧栏顶部的 **「+」**（新建会话）；
2. 在弹窗中**选择智能体**；
3. 在底部输入框输入你的需求，按 `Enter` 发送（`Shift+Enter` 换行）。

### 4.1 选择智能体

弹窗里挑用哪个 AI CLI 来干活，可以设为默认。

![选择智能体](screenshots/dialog-agent-picker.png)

弹窗列出服务端已安装的全部 AI CLI。每个智能体卡片显示：图标、名称、一句话定位、标识名、默认模型。

- 带「**默认**」标记的是当前默认智能体，新建会话时优先选中它
- 卡片右侧按钮可**设为默认**或进入**配置页**
- 若列表为空，说明服务端未安装任何 CLI，需先在「设置 → 智能体」中重新扫描

### 4.2 切换项目

从顶栏项目下拉切换或新增项目，也能看到最近打开的文件。

![项目下拉菜单](screenshots/dialog-project-select.png)

点顶栏的项目名展开下拉，包含：

- **项目列表**：每个项目显示名称、路径与角标（会话数等）
- **最近文件**：当前项目最近打开的文件，点击直接打开
- **快捷操作**：任务页搜索、全局搜索等

AI 会以流式方式回复，你可以实时看到它的思考过程与工具调用。

# 第二部分：功能详解

## 5. AI 对话

和 AI 聊天相关的全部操作：输入、命令、附件、消息操作、审批、会话设置。

### 5.1 输入栏

底部那条输入区，负责打字发消息，以及会话级的一排操作按钮。

![聊天输入栏](screenshots/chat-01-input.png)

输入栏从上到下分为几层：

**顶部操作条**（会话级操作）：

| 按钮 | 作用 |
|---|---|
| 会话列表 | 打开会话抽屉 |
| 新建会话 | 新建（长按可选智能体） |
| 会话搜索 | 打开搜索抽屉 |
| 消息索引 | 打开用户消息索引，快速跳转到某条消息 |
| 同步外部会话 | 把 ACP 外部会话同步进来 |
| 归档 | 归档当前会话 |
| 自动朗读 | 开关 AI 回复的自动语音朗读 |
| 刷新会话 | 重新拉取当前会话 |

**输入区**：

- **附件按钮**（回形针）：打开附件抽屉
- **输入框**：支持多行；占位符会轮播提示
- **发送按钮**：有内容时发送；**空输入时点它会弹出「快捷发送」菜单**（见 [5.3 快捷发送](#53-快捷发送)）
- **停止按钮**：流式进行中出现，点击可取消当前回合（需二次确认）

**底部信息行**：

- **上下文用量条**：显示当前上下文占用量，点击展开详情弹窗（含「压缩」按钮）
- **模型**：点击打开会话设置抽屉
- **模式**：点击/长按切换（如自动、只读等）

### 5.2 斜杠命令

输入 `/` 调出命令菜单，快速执行内置命令或智能体自带的命令。

在输入框输入 `/` 会弹出命令菜单：

![斜杠命令菜单](screenshots/chat-02-slash.png)

菜单分两组：

- **内置命令**（ClawBench 提供，带「内置」标签）：`/cb-chatsearch` 搜索聊天历史、`/cb-task` 管理任务、`/cb-usage` 查看 token 用量等
- **智能体命令**（来自当前 AI 后端）：如 `/background`、`/branch`、`/btw` 等，取决于所用 CLI

用上下键选择，`Enter` 或点击确认。斜杠命令必须位于消息**开头**才生效。

### 5.3 快捷发送

把常用 Prompt 存起来一键发送，省去反复打字。

把常用 Prompt 存成快捷项，一键发送，省去重复输入。

**调用**：清空输入框后点**发送按钮**（或点它旁边的下拉），弹出快捷发送菜单：

![快捷发送菜单](screenshots/chat-05-quicksend-menu.png)

- **单击条目**：直接发送这条 Prompt
- **点条目右侧的填入图标**：只把内容填进输入框，你可以先改再发（适合「套模板 + 补参数」）
- **点「编辑」**：打开管理抽屉

**管理**：点「编辑」进入快捷发送抽屉：

![快捷发送抽屉](screenshots/chat-06-quicksend-drawer.png)

| 操作 | 说明 |
|---|---|
| **拖动左侧手柄（≡）** | 调整顺序，顺序会持久化到服务端 |
| **点条目** | 编辑内容 |
| **右上角「+」** | 新增快捷项 |
**消息聚类**（Message Clustering）将同一主题的多轮对话自动归为一组，方便回溯与整理。聚类基于消息内容语义与时间间隔进行 Union-Find 三阶段合并：
1. **语义相近**：连续若干轮对话若讨论的是同一主题，则合并
2. **时间合并**：间隔短的多轮对话段若主题相关则合并
3. **边界识别**：若两段之间有明显的话题转换（如新问题或新文件），则分开

聚类结果以折叠卡片形式展示，用户可点击展开查看完整多轮对话。适合长会话中快速定位到之前讨论过的某个子话题。

| **右上角 ✨** | 打开消息聚类抽屉（从历史消息里发现可复用的 Prompt） |
| **右上角「⋮」** | 导出 / 导入 JSON（便于备份与跨设备迁移） |

快捷项按用户存储（不区分项目），因此换项目也能用。

### 5.4 附件与引用

把文件或选中的文字片段作为上下文带给 AI。

| 方式 | 操作 |
|---|---|
| **附件按钮** | 点回形针 → 附件抽屉（当前文件 / 引用 / 分享 / 上传历史四个页签） |
| **拖拽** | 直接把文件拖到输入框 |
| **粘贴** | 直接粘贴剪贴板中的图片或文件 |
| **@ 引用** | 输入 `@` 唤出文件选择菜单，把文件内容作为上下文带入 |
| **行范围引用** | 引用文件时指定行范围，只把需要的片段送给 AI |
| **选中文本引用** | 在聊天里选中文字，会弹出引用问答栏，可直接针对该段提问 |
| **面包屑拖拽** | 把文件管理器的路径面包屑拖到输入框 |

附件抽屉从输入栏左侧的回形针打开，含「当前 / 最近引用 / 最近分享 / 最近上传」四个来源：

![附件抽屉](screenshots/chat-07-attach-drawer.png)

### 5.5 消息操作

每条回复下面那排按钮，以及聊天区里的思考、工具、耗时等元素。

![消息操作与推荐回复](screenshots/chat-04-message-actions.png)

每条 AI 回复下方有一排操作按钮：

| 按钮 | 作用 |
|---|---|
| **摘要** | 切换摘要视图（AI 生成的要点式总结） |
| **朗读** | 语音朗读这条回复 |
| **复制** | 复制全文 |
| **分叉会话** | 从这条消息创建一个新分支会话 |
| **回溯会话** | 把会话截断到这条消息处并重启 AI |
| **查看详情** | 打开元数据弹窗（模型、耗时、Token 用量等） |

用户消息同样支持复制与查看详情。

其他聊天区元素：

- **深度思考**：AI 的推理过程，默认折叠，点击标题展开
- **工具调用**：以胶囊/卡片形式展示，点击展开详情
- **耗时标注**：每条回复下方显示本轮耗时
- **文件变更横幅**：本轮改了哪些文件，点击打开抽屉
- **计划面板**：AI 的多步计划及进度
- **滚动悬浮按钮**：快速跳到上一条/下一条消息、顶部/底部
- **代码块头按钮**：代码块右上角的复制、换行、附加到聊天

### 5.6 工具调用与权限审批

看 AI 用了哪些工具，并在它要动文件或跑命令时决定允不允许。

AI 执行操作时会显示工具调用卡片。点击卡片可展开查看完整输入输出。

当 AI 请求执行**有副作用**的操作（写文件、执行命令等）时，会弹出**权限审批卡片**，包含：

- 工具名称与详情
- **允许** / **拒绝** 按钮

选择结果会被记住用于本次会话。若开启了自动批准，则会显示「已自动批准」标记。

![工具调用与权限审批](screenshots/chat-08-tool-approval.png)

上图为一次命令执行：顶部是「权限请求」卡片（展开显示完整命令，批准后标记「已批准」），下方是「深度思考」与多个 Bash 工具调用卡片。

### 5.7 提问卡

AI 需要你选择时给出的可点选项卡片，选完提交即可。

当 AI 需要你做出选择时，会渲染**交互式选项卡片**而非纯文本：

- 单选/多选选项，点击选中
- 可选的**补充说明**输入框
- **推荐**按钮（AI 给出的建议选项）
- **提交**按钮

已选项会跨重渲染保持，可以反悔重选。

![提问卡](screenshots/chat-09-ask-question.png)

卡片中含单选 / 多选选项、可选的「补充信息」输入框，以及底部的「推荐」与「提交」按钮。

### 5.8 推荐回复

AI 回复完后给出的下一步建议，点一下就能填进输入框。

AI 回复完成后，输入框上方会出现若干**下一步建议**（见上方截图）。点击文本会展开，点「填入」按钮把它放进输入框。

这是基于当前上下文实时生成的，可在设置中关闭。

### 5.9 会话设置

针对当前会话调整模型、思考档位、消息显示模式、权限模式等。

点击输入栏底部的**模型**或**模式**，打开会话设置抽屉，含四个页签：

![会话设置抽屉](screenshots/sess-05-settings-drawer.png)

| 页签 | 内容 |
|---|---|
| **模型** | 切换当前会话使用的模型 |
| **思考** | 调整思考等级/预算 |

> **深度思考档位说明**：低档（Thinking Budget ≈ 200）适合简单问答；中档（≈ 800）适合常规开发任务；高档（≈ 3200+）适合需要多步推理的复杂任务如架构设计或深度调试。思考档位越高，AI 的推理 token 越多，响应会稍慢但质量更稳定。

| **消息显示模式** | 混合 / 仅摘要 / 仅原文 |

> **消息显示模式**：混合模式（默认）同时展示摘要卡片与原始消息，适合概览与细节兼顾；仅摘要模式只显示 AI 生成的摘要卡片，省界面空间；仅原文模式只展示原始消息，无摘要。切换模式后，新加载的消息按新模式显示，已加载的消息不受影响。

| **模式** | 切换权限模式（如自动批准） |

> **分叉上下文预算**：分叉时携带的历史上下文上限，单位为 token 数。值越小，分叉后新会话越轻量但上下文越少；值越大则保留更多历史但 token 消耗增加。默认值适中，修改后建议观察实际效果。

| **传输** | 查看/切换后端传输方式 |

> **推荐回复上下文条数**：生成推荐回复时参考的最近消息轮数。值越大，推荐内容越丰富但计算略慢；值越小推荐越精简。设为 0 则关闭推荐回复。

抽屉内还有「设为默认」与「自动批准」开关。

### 5.10 流式过程中的操作

AI 还在输出时你能做的事：插话、取消、重置会话。

- **插话（steer）**：流式进行中直接发送新消息，会在当前回合的合适位置插入，不必等 AI 说完
- **取消**：点停止按钮取消当前回合
- **重置会话**：会话卡死时，用错误横幅上的按钮重启 AI 进程，对话上下文保留

> **文件变更自动刷新**：AI 在对话过程中修改了文件后，ClawBench 会自动将文件管理器中对应的文件标记为已修改（高亮显示）。用户无需手动刷新即可看到最新内容。该刷新为单向感知（仅感知外部变化），不会覆盖用户未保存的编辑。

### 5.11 应用内完成通知

后台发生会话、任务或仓库事件时滑入的提示卡片，告诉你"有事发生了"并让你一键跳过去。

当聊天界面不在前台时，会话/任务/仓库事件会滑入一张**纯通知卡片**——它只是一条通知，不是可以就地操作的迷你界面：

| 行为 | 说明 |
|---|---|
| **事件覆盖** | 会话完成/取消/待审批、任务启动/完成/失败/取消、仓库议题与合并请求的六类变化，与系统通知完全一致 |
| **头部** | 智能体图标 + 主类别徽章（会话 / 任务 / 议题与合并）+ 事件类型标题（如「会话已完成」「任务失败」「合并请求 #42 · 已合并」，纯文字、按语义配色、14px）+ 关闭按钮 |
| **正文** | 标题段（会话名 / 任务名 / 仓库）+ 最多 4 行纯文本摘要（字号与聊天正文一致） |
| **跨项目标识** | 事件属于其他项目时，整张卡片换色，底部额外显示「外部」标签 + 加粗的项目名 + 完整路径 |
| **位置** | 桌面端右下角滑入；移动端顶部滑下 |
| **跳转** | 点击整张卡片跳到对应会话 / 任务执行详情 / 议题与合并页签，并顺带把该条标记为已读 |
| **关闭** | 点击卡片上的关闭按钮 |
| **自动关闭** | 5 秒无操作自动消失（错过的内容靠未读角标找回）；鼠标悬停在卡片上时倒计时暂停，移开后继续走完剩余时间 |
| **非模态** | 卡片不会挡住页面其他操作，点击别处也不会把它关掉 |
| **队列** | 多个事件依次展示，最多排队 3 条；同一仓库的仓库事件合并成「N 条新变化」一条 |
| **开关** | 设置 → 推送通知 → 应用内通知。关闭后不再弹新卡片，不影响提示音与系统/IM 推送 |

> 想看完整内容时，点卡片跳转到会话即可——卡片本身不再提供展开预览或快捷回复。

### 6.2 会话搜索

用关键词或语义搜索历史会话，带归档、排序、时间等筛选。

### 6.3 会话标签

给会话贴自定义分类标签，之后按标签筛选，方便归类。

标签用来给会话分类，便于在侧栏里快速筛出同类会话。标签显示在会话条目的**最底部一行**，颜色按标签名哈希映射到统一调色板，因此同一标签在任何地方颜色都一致。

#### 设置标签

在会话上右键打开弹窗，勾选已有标签或新建标签。

在会话条目上**右键 → 设置标签**，打开标签弹窗：

![设置标签弹窗](screenshots/sess-03-tag-dialog.png)

弹窗分两块：

**已有标签**：列出全部候选标签（全局标签 + 当前项目的标签）。点标签卡片即可**选中 / 取消**，支持多选。已选中的卡片有高亮边框。

**新建标签**：输入名称后点「+ 创建」。创建前需选择作用范围：

| 范围 | 含义 |
|---|---|
| **仅本项目** | 标签只在当前项目内可见、可用（默认） |
| **全局** | 标签在所有项目中都可见、可用 |

![新建标签](screenshots/sess-04-tag-create.png)

改完点底部**确定**保存，**取消**放弃。

标签名会自动去除首尾空白并转为小写，因此 `Bug` 与 `bug` 是同一个标签。

#### 标签作用范围

说明「仅本项目」和「全局」两种标签的区别与适用场景。

| 范围 | 可见性 | 适用场景 |
|---|---|---|
| **项目内** | 仅当前项目 | 与某个项目强相关的分类，如「待发布」「重构中」 |
| **全局** | 所有项目 | 跨项目通用的分类，如「待验证」「重要」 |

**项目隔离**：不同项目可以有同名标签，互不影响。例如 A 项目的「bug」和 B 项目的「bug」是两个独立标签，各自维护自己的颜色与关联会话。

> **提示**：把标签从项目内改成全局**不会**自动发生——标签的范围只在创建时确定。给会话重新打标签时，已存在标签会保留原有范围。

#### 标签过滤栏

会话列表上方那一行标签按钮，点一下就只看这类会话。

只要当前项目里有**正在使用**的标签，会话列表上方就会出现一条横向的标签过滤栏：

- **只列出当前项目实际在用的标签**（避免出现点了必然为空的选项），并显示每个标签下的会话数
- **点击标签筛选**，再点一次取消筛选
- 筛选在服务端完成，因此分页加载的会话也能被正确筛出（不会出现「明明有匹配却要滚很久才出现」）
- 当前项目没有在用标签时，整条过滤栏隐藏
- 跨项目会话分组**不显示**标签行，也不参与标签筛选

#### 删除标签

在标签弹窗里把某个标签整个删掉，同时解除它与所有会话的关联。

在标签弹窗中，把鼠标移到标签卡片上，点出现的**删除按钮**即可删除该标签本身（同时解除它与所有会话的关联）。

> **注意**：删除标签是按**范围**精确删除的。若同名标签同时存在「全局」和「项目内」两条，删除时只会删掉你所见的那个范围，不会误删另一个。

### 6.4 分叉与回溯

从某条消息另起一个新方向，或退回某条消息重来。

- **分叉**：从某条消息创建对话分支，原会话不受影响。分叉会带上压缩后的上下文（预算可在设置中调整）。
- **回溯（Rewind）**：把会话截断到某条消息处并重启 AI 会话，用于「走错路了重来」。回溯会同时清空计划面板。
- **续接**：在已有会话基础上开新会话，标题会带时间戳前缀。

## 9. 标注与跳转系统

自动把聊天里出现的路径、commit、端口变成可点击的链接，点一下就跳过去。

ClawBench 会自动识别聊天与文档里的**技术引用**（文件路径、commit hash、worktree 路径、localhost 地址），把它们变成可点击的标注。点一下就能跳到对应位置，不必手动复制路径再去找。

### 9.1 标注类型总览

一张表列出能被识别的几类引用，以及点击后会发生什么。

| 类型 | 外观 | 点击后 |
|---|---|---|
| **文件路径** | 蓝色等宽文字，悬停下划线 | 打开文件查看器并定位到该行 |
| **代码链接预览** | 同上，但在**预览模式**下 | 弹出代码切片浮层，不离开当前页面 |
| **Commit hash** | 短 SHA + 打开图标 | 切到项目历史并定位到该提交详情 |
| **Worktree 路径** | 蓝色等宽文字 + 图标 | 打开该工作树下的文件 |
| **localhost 地址** | 地址 + 打开图标 | 建立端口映射并打开 WebView |

标注是**基于 DOM 遍历**生成的（不是简单正则替换），因此会先验证路径真实存在再标注——不存在的路径保持纯文本，避免点了打不开。

### 9.2 文件路径标注

聊天里出现的文件路径会变成可点文字，点击打开文件并定位到对应行。

聊天里出现的文件路径会自动变成可点击标注：

![文件路径标注](screenshots/annot-02-filepath.png)

标注支持 `路径` 与 `路径:行号` 两种形式（如 `cmd/server/main.go:1415`）。

**点击后**打开文件查看器并**直接定位到对应行**：

![文件路径跳转](screenshots/annot-04-filepath-jump.png)

**双候选路径解析**：同一个相对路径可能相对于「当前文件所在目录」或「项目根目录」，ClawBench 会两个候选都试，哪个存在用哪个。所以文档里写 `../images/a.png` 和 `web/src/app.ts` 都能正确解析。

### 9.3 代码链接预览

在预览模式下点路径不跳走，而是在当前页弹一个小浮层看代码。

在**预览模式**下（文件管理器工具栏开启「预览模式」），点击路径不再跳转，而是弹出**代码切片浮层**：

![代码链接预览](screenshots/annot-05-code-link-preview.png)

浮层包含：

| 元素 | 说明 |
|---|---|
| **标题栏** | 文件名 + 行号引用（如 `cmd/server/main.go:1415`） |
| **目录** | 文件所在目录（长路径跑马灯滚动） |
| **代码区** | 目标行上下文的代码切片，带语法高亮与行号 |
| **展开条** | 向上/向下加载更多上下文行 |
| **操作按钮** | 固定卡片、关闭、复制路径、在完整查看器中打开 |

浮层是**临时卡片**（transient）：点卡片外部会关闭；点「固定」按钮则常驻，方便边看代码边对话。

> **提示**：若点击路径直接跳转了查看器而不是弹浮层，说明**预览模式未开启**。开启后即为浮层模式。

> **为何有时不弹浮层直接跳转到查看器？**：这是因为「预览模式」未开启。代码链接预览浮层依赖预览模式开关——开启时点击路径弹浮层，关闭时点击路径直接跳转到完整查看器。如需使用浮层预览，请先在文件管理器工具栏开启「预览模式」。

### 9.4 Commit hash 标注

聊天里的短 commit id 可以点击，直接跳到该提交的详情页。

聊天里出现的短 commit hash 会附带一个打开图标：

![Commit 标注](screenshots/annot-01-commit.png)

**点击后**切到「项目历史」并**直接定位到该提交的详情页**：

![Commit 跳转](screenshots/annot-03-commit-jump.png)

详情页显示 SHA、作者、时间、提交说明与变更文件列表，可继续查看 diff。SHA 本身也可点击复制。

### 9.5 Worktree 路径标注

多工作树环境下，聊天里的 worktree 路径也能点击打开。

在多工作树（worktree）环境下，聊天里出现的 worktree 路径会被识别并标注。worktree 标注**优先于**文件路径标注——避免 worktree 路径被当作普通相对路径二次匹配。

### 9.6 localhost 地址标注

聊天里的 `localhost:端口` 可以点击，自动建隧道并打开页面。

聊天里出现的 `localhost:PORT` 或 `127.0.0.1:PORT` 会附带一个打开图标。点击后 ClawBench 会：

1. 为该端口建立 SSH 隧道（端口映射）
2. 在内置 WebView 中打开该地址

这让「AI 说服务跑在 localhost:3000」到「我直接看到页面」变成一次点击。

### 9.7 标注管道的处理顺序

几类标注按固定先后识别，避免互相误匹配。

四种标注按固定顺序处理，且**已标注的元素不会被后续标注重复匹配**：

```
Worktree 标注 → 文件路径标注 → localhost 标注 → commit hash 标注
```

这个顺序有实际意义：worktree 路径本身就是文件路径，必须先识别为 worktree 才不会被子路径标注误处理。

### 9.8 流式期间的行为

AI 还在输出时不做标注，等这一轮结束、内容稳定后再做。

**流式输出进行中，标注管线不运行**——此时只做纯 Markdown 渲染。等这一轮回复结束、内容稳定后，才启动完整管线（含路径验证与标注）。

这样做的原因：流式期间内容不完整，路径可能只写了一半，此时标注会产出大量无效结果并造成闪烁。

面板顶部有**仓库徽标**（点击可改绑定 / 打开仓库 / 解绑）、**全部标记已读**、**刷新**。

四个页签：

| 页签 | 内容 |
|---|---|
| **动态** | 聚合未读 / 已读 / 全部条目，后台轮询感知变化 |
| **议题** | Issue 列表，支持状态筛选（开启/已关闭/全部）与「我的」筛选（分配给我/我提的/待我 review） |
| **合并** | PR / MR 列表，筛选同上 |
| **流水线** | CI 流水线列表，显示状态、分支、提交、事件类型 |

点任意条目进入详情：正文、状态徽标、关联 CI、评论区（可加载更多）。PR 详情可展开关联的流水线。

**仓库绑定**：优先从项目 git remote 自动识别并绑定（官方 host 自动绑定，自建实例需确认 host），也可手动填 URL；绑定关系随项目走。自建实例同时支持 http 与 https——host 仍是身份键，同一实例两种协议访问到的仍是同一个仓库。

**变化感知与未读**：后台轮询仓库变化，页签显示未读徽标；六类事件（新开 / 关闭 / 合并 / 重开 / 评论 / CI 完成）可分别开关通知。未读按**条目**计数——同一 issue 的三条评论算一条未读，可单条标记已读，也可整仓库一键清除。

**动态页签**：聚合所有条目并可在未读 / 已读 / 全部之间切换（默认未读），带行级已读标记与「有新评论」这类事件原因文案。

**事件触发任务**：任务可选「触发方式：事件」，订阅 `issue.opened`、`pr.merged`、`pipeline_done` 等事件；事件到达自动唤起 AI 任务，prompt 前置只读的事件上下文（仓库、编号、标题、链接、作者、评论正文等按事件类型条件注入），执行记录可深链回原始 issue/PR。

**引用到对话**：详情页 header 的引用按钮把 issue/PR 作为 URL 附件带入聊天（chip 显示 `owner/repo#123`），可再划取文本补充；正文也支持双击复制与划取引用。

**凭据与安全**：token 按 `(平台, host)` 隔离存储（自建 GitLab 各自独立），配置接口只回传存在性、不回传明文；自建实例可开启「跳过 TLS 校验」支持自签名证书（默认关，有安全风险）。内网 / 自建 host 服务端不拦截，改在绑定弹窗里提示。

> **提示**：GitHub API 有速率限制。若提示 `API rate limit exceeded`，稍后再试或换用 token。

> **AI 自身事件抑制**：当 AI 在对话中执行了某个操作（如在 GitHub 上评论了 Issue），该操作产生的事件**不会再次触发**任务执行，以避免 AI 动作 → 事件触发 → AI 再次响应 → 死循环。抑制基于事件来源判断（AI 自身操作的发起方与当前 Agent 一致时跳过）。

## 16. 多项目与 Worktree

同时处理多个项目或分支：切项目，或把某个工作树当成独立项目打开。

- 顶栏可随时切换项目，各项目的会话、任务、Git 状态完全独立。
- 切换项目时会保留聊天输入草稿。
- 对需要隔离的开发工作，用 Git 面板的 **Worktree** 功能创建独立工作区，避免污染主目录。
- **Worktree 作为独立项目**：在「项目历史 → 管理 → 工作树」里，可以把某个工作树**作为独立项目打开**。这意味着该 worktree 有自己独立的会话列表、标签、文件浏览位置，与主项目完全隔离。可以同时在多个 worktree 对应的项目间切换，并行处理不同分支上的任务。
- **Worktree 路径标注**：在多 worktree 环境下，聊天中出现的其他 worktree 路径会被自动识别并标注（显示为蓝色可点击文字），点击可直接跳转到该 worktree 下的文件。标注优先级高于普通文件路径标注，避免 worktree 路径被误匹配为子路径。
- 其他项目的会话会出现在会话列表的跨项目分组中，点击直接跳转（注意跳转后是在**那个项目**的上下文中对话）。

## 17. 上下文、摘要与分叉

长会话如何自动压缩历史、生成摘要，以及分叉与回溯的区别。

- **上下文压缩**：对话很长时会自动压缩历史，优先保留全部用户消息，助手条目按预算填充。预算可在设置中调整。
- **摘要**：长回复可生成摘要卡片，快速回顾结论；消息显示模式可设为「仅摘要」。
- **分叉**：从任意一条用户消息创建对话分支，原会话不受影响。分叉会带上压缩后的上下文。
- **回溯（Rewind）**：把会话截断到某条消息处并重启 AI 会话。
- **续接**：在已有会话基础上开新会话，标题会带时间戳前缀。

## 18. 推送通知

说明各种通知渠道：应用内、系统通知、钉钉/飞书、离线补拉。

- **应用内通知**：会话完成/取消/待审、任务启动/完成/失败/取消、Forge 新动态都会以纯通知卡片弹出——点击整卡跳转并顺带标记已读，5 秒自动关闭。详见 [5.11 应用内完成通知](#511-应用内完成通知)。

![完成通知](screenshots/00-completion-popover.png)

- **通知音效**：可在设置中关闭（避免蓝牙耳机被中断）。
- **钉钉 / 飞书**：可配置企业机器人，把通知推送到 IM。支持 Markdown 单聊与交互式卡片。
- **离线事件**：WebSocket 断开期间的事件会被持久化，重连后按游标补拉，不会丢通知。

## 19. 常见问题

使用中容易遇到的疑问与解决办法。

**Q：AI 一直不回复 / 卡住了？**
检查会话是否在运行（有停止按钮）。若确实卡死，用错误横幅上的**重置会话**按钮重启 AI 进程，对话上下文会保留。

**Q：刷新页面后消息没了 / 重复了？**
ClawBench 以数据库为权威。刷新会从 DB 重建消息列表。若仍异常，说明后端尚未把流式内容落库，稍等片刻再刷新。

**Q：升级提示怎么处理？**
发现新版本时会弹出升级卡片：

![升级提示](screenshots/00-upgrade-dialog.png)

可选「立即升级 / 跳过此版本 / 稍后提醒」。Docker 部署下会额外提示：容器内可自升级，但重建镜像会回退，建议改用 `docker pull` 更新镜像。

**Q：某个功能找不到？**
大部分功能都在左侧 Dock 的九个图标里。设置类选项统一在最后一个「设置」图标。若 Dock 里没有终端或端口映射，说明该功能在服务端被禁用或平台不支持。

**Q：界面元素太小 / 太大？**
设置 → 外观 → **界面缩放**，可在 80%–150% 之间调整。

**Q：Forge 提示 API rate limit exceeded？**
GitHub API 有速率限制。稍后再试，或在设置 → GitHub/GitLab 集成中换用有效 token。

**Q：代码存量一直显示「加载中」？**
首次计算需要扫描全项目，耗时较长（大项目可能数十秒）。等待即可。
