# 微信推送配置

ClawBench 支持通过个人微信推送通知：AI 会话完成、权限审批、任务状态变更时，消息直接发到你的微信单聊。

与钉钉/飞书最大的区别是**没有密钥可填**——微信通道靠扫码授权，连接过程本身就是一个登录流程。

> **风险提示**：该通道基于个人微信的非官方接口，账号存在被限制的风险，请自行评估后使用。企业内部使用建议优先选钉钉或飞书。

---

## 在界面中配置与使用

推送相关开关集中在 **设置 → 推送通知**。

| 设置项 | 说明 |
|---|---|
| **推送方式** | 原生 / 钉钉 / 飞书 / 微信 / 关闭；选择微信后出现扫码登录面板，无需填写任何密钥 |
| **应用内完成通知** | 会话/任务完成时弹出卡片，点击整卡跳转并顺带标记已读，5 秒自动关闭 |
| **任务完成提示音** | 通知音效；关掉可避免蓝牙耳机被中断 |
| **浏览器系统通知** | 页面最小化或不在前台时，用操作系统通知提醒会话完成、任务完成、需要审批和仓库事件 |

> **「推送方式」与「浏览器系统通知」互不影响。** 前者选的是**手机与 IM** 通道，设成「关闭」只表示不再往手机和 IM 发消息；只要「浏览器系统通知」开着，网页端最小化时仍会弹系统通知。若想彻底静音，两处都要关。

> **离线事件**：WebSocket 断开期间的事件会被持久化，重连后按游标补拉，不会丢通知。

## 配置步骤

### 1. 选择推送方式

打开 **设置 → 推送通知**，把「推送方式」切换为 **微信推送**。面板会显示「尚未登录微信」和一个「扫码登录」按钮。

### 2. 扫码登录

1. 点击 **扫码登录**
2. 用手机微信扫描面板上出现的二维码
3. 在手机上确认登录

面板状态会依次经过「等待扫码」→「已扫码，请在手机上确认」→「登录成功」，随后显示为「已连接」以及本次授权对应的 **Bot ID**。

> 二维码有效期有限，过期后点「重新获取二维码」即可。整个登录流程最长约 8 分钟，超时会自动结束。

### 3. 先给机器人发一条消息

微信平台**不提供静态的用户名单**：一条出站消息必须带 `context_token`，而这个 token 只在**你给机器人发消息时**由平台下发。

所以登录成功之后，还需要在微信里找到这个机器人并**随便发一条消息**。在那之前，ClawBench 无法主动给你推送——面板显示「已连接」只代表登录有效，不代表推送链路已经打通。

### 4. 退出与重新登录

面板上的 **退出登录** 会清掉授权；**重新扫码** 用于更换账号或修复失效连接。

如果微信侧结束了本次会话（例如在其他设备登录挤掉了它），面板会显示「**微信连接已失效**」并提示重新扫码。此时令牌仍然保留，但推送不会到达，必须重新登录才能恢复。

## 使用说明

微信通道与钉钉/飞书共用同一套会话命令，交互行为一致。

### 订阅通知

向机器人发送任意消息即可完成订阅，你会收到一条回复。之后会话完成、任务状态变化等事件都会推到这条单聊里。

### 查看会话列表

发送 `/ls`：

```
会话列表
发送 @会话ID <消息> 向会话发送消息：

/path/to/project
- @a1b2c3d4 修复登录Bug *
- @e5f67890 添加用户功能

/path/to/another
- @b3c4d5e6 代码重构
```

`*` 表示该会话正在运行中。

### 向会话发送消息

1. **点名会话**：`@会话ID 消息内容`（ID 取列表里的前 8 位十六进制，支持更长前缀以消歧义）

   ```
   @a1b2c3d4 请继续修改
   ```

2. **发给你最近用过的会话（粘性会话）**：直接发送**不带 `@` 前缀**的文本，会发给**你上一次 `@` 过的那个会话**。

   > 如果还没有粘性目标，直接发文本会收到一条提示，引导你先用 `/ls` 选择。

> **附件**：直接发送图片或文件，会作为附件发给当前目标会话。语音消息优先使用微信自带的转写文字；没有转写时会明确回复「暂不支持该消息类型」，而不是静默丢弃。

### 回看最后一条回复

推送通知里的回复是截断版，想看更多内容发送 `/show`：

- `/show` — 发回**当前会话**（粘性会话）最后一条 AI 回复
- `/show a1b2c3d4` — 指定会话

只返回**已生成完成**的完整回复（同一轮里被拆成多段文字时会合并返回）。如果该会话还没有任何回复，机器人会明确告知。

**当前回合仍在生成时**，回复会额外注明「以下为上一条已完成的回复」——正在生成的半截内容不会被返回。

> **微信单条消息上限约 2000 字**，这是三个渠道里最小的（钉钉/飞书约 4000）。超长部分以省略号截断。
>
> 注意微信的**推送预览本身也是 2000 字**，所以这里的 `/show` 拿到的是「最多 2000 字的完整答案」，而不是无限长——想要更长的内容，请在 Web 界面里查看该会话。

会话 ID 只接受**8 位以上十六进制前缀**（或完整会话 ID）；`/show a`、`/show %` 这类参数会被直接拒绝，不会去猜会话。

### 停止会话并清空队列

- `/stop` — 停止**当前会话**正在执行的回合，并清空它的排队消息
- `/stop a1b2c3d4` — 指定会话

回复会区分「已停止运行中的会话」和「会话本来就没在运行」，并给出清空的排队消息条数。

### 新建会话

`/new` 会返回**全部项目**及其序号：

```
新建会话
发送 /new 序号 或 /new 完整路径 在指定项目下新建会话：

1. `/path/to/project-a`
2. `/path/to/project-b`

用法：/new 1
```

- `/new 1` — 在第 1 个项目下用**默认智能体**新建一个空会话
- `/new /path/to/project-a` — 用完整路径指定项目

创建成功后，机器人会**自动把这个新会话设为你的当前会话**，之后直接发消息就会进入它。同时，已打开的网页端会立刻出现这个新会话，无需等第一轮结束。

> 只支持**序号**和**完整路径**，不支持只写目录名——同名目录无法区分，写错会建到错误的项目里。
>
> 序号按**项目路径**排序，因此固定不变：建完会话后，同一条 `/new 2` 仍然指向同一个项目。
>
> 项目很多时列表会按微信单条消息上限截断，末尾会注明「仅显示前 N 个（共 M 个）」。被截掉的项目仍可用 `/new 完整路径` 指定。

### 命令优先级

`@会话ID` 的优先级**高于**所有命令。因此 `@a1b2c3d4 /new` 会把 `/new` 当作普通文本发给该会话，而不是执行新建——这也是把命令字样发给 AI 的办法。命令只在消息**以它开头**时才生效，写在句子中间（如 `please /stop it`）按普通文本处理。

命令**不能和附件一起发送**。如果一条消息既有图片/文件又有命令词，机器人会提示你分两步发——命令本身不需要附件，而把附件单独投进会话会丢掉你的命令。

### 推送通知类型

| 事件 | 说明 |
|------|------|
| 会话已完成 | AI 会话执行完成，附带响应预览 |
| 会话已取消 | AI 会话被用户取消 |
| 操作需批准 | AI 请求执行需要审批的操作（如 Bash 命令、文件修改） |
| 任务已启动 | 任务开始执行 |
| 任务已完成 | 任务执行成功，附带响应预览 |
| 任务失败 | 任务执行失败 |
| 任务已取消 | 任务被取消 |

> 当有 WebSocket 客户端连接到 ClawBench（用户正在使用 Web 界面）时，推送通知会被自动抑制，避免重复提醒。

> 微信通道发的是**纯文本**：Markdown 会被拍平成纯文本（标题、加粗、表格符号都会去掉），代码块内容保留。这是微信客户端的渲染限制，不是内容丢失。

## 与钉钉、飞书的差异

| 维度 | 钉钉 / 飞书 | 微信 |
|---|---|---|
| 凭据 | 手填 AppKey/AppSecret | **扫码登录**，无密钥 |
| 消息格式 | Markdown / 交互式卡片 | 纯文本（Markdown 剥离） |
| 单条上限 | 约 4000 字 | **约 2000 字** |
| 主动推送前提 | 任意时刻 | **必须你先生给机器人发过消息** |
| 群聊 | 支持 | **不支持**，仅单聊 |
| 订阅名单 | 可在设置里手动增删 | **不能**，只有给机器人发过消息的人才会收到 |

## 常见问题

**Q: 显示「已连接」但收不到推送？**

A: 先确认你**给机器人发过至少一条消息**。没有入站消息就没有 `context_token`，ClawBench 无法主动发出任何消息——这是微信通道与钉钉/飞书最大的使用差异。

**Q: 之前能用，突然收不到了？**

A: 看设置面板是否显示「微信连接已失效」。微信侧结束会话后（换设备登录、长时间不活跃等），令牌还在但通道已死，需要点「重新扫码」重新登录。

**Q: 机器人不回我消息？**

A: 确认当前「推送方式」是**微信推送**。切到钉钉/飞书或「关闭」后，微信侧的机器人不会再处理入站消息。

**Q: 能把机器人拉进微信群吗？**

A: 不能。该通道的出站消息结构只有「发给某个用户」，没有群寻址字段，群推送在当前 SDK 下无法实现。

**Q: 推送模式如何切换？**

A: 在设置面板中选择不同的推送模式即可。钉钉、飞书、微信互斥，切换后各自的登录状态与订阅数据不会丢失，切回来仍可使用（微信需要 token 仍有效）。
