# ClawBench 使用手册

ClawBench 是面向手机 / 平板 / 桌面的多端 AI 工作台。本手册同时适用于**桌面端**（电脑浏览器）与**移动端**（手机 / 平板浏览器、Android App）；两端差异处用 **桌面端** / **移动端** 标注。

> 功能概览见仓库根 [README](../../README.md#核心功能)。

本手册为**索引式**：每个章节给出该功能的概览，详细操作、截图与边界情况见对应的详解文档。

---

# 第一部分：快速上手

## 1. 登录

打开 ClawBench 的第一步：输入访问密码，验证身份后进入工作台。

**详解**：[快速上手](getting-started.md) · [公网访问](PUBLIC_ACCESS.md) · [在 Termux 上完全运行](TERMUX.md)

## 2. 选择项目

项目就是服务器上的一个目录，切换项目等于切换整套工作环境（会话、任务、Git、文件都跟着变）。

**详解**：[快速上手](getting-started.md) · [多项目与 Worktree](projects.md)

## 3. 界面总览

**桌面端**为宽屏三栏布局（左侧功能栏、中间聊天区、右侧会话列表）；**移动端**为底部 Dock 单栏布局。

**详解**：[快速上手](getting-started.md)

## 4. 发起第一次对话

从零开始：新建会话、选智能体、输入需求、看 AI 流式回复。

**详解**：[快速上手](getting-started.md)

# 第二部分：功能详解

## 5. AI 对话

和 AI 聊天相关的全部操作：输入、命令、附件、消息操作、审批、会话设置。

**详解**：[AI 对话](chat.md)

## 6. AI 群聊

把多个智能体拉进同一个会话，围绕同一话题多智能体讨论：主持人模式 / 自由模式、成员管理、@ 与密送；并说明智能体从哪来、如何配置。

**详解**：[AI 群聊](group-chat.md)

## 7. 会话管理

会话的增删改查：侧栏 / 列表、搜索、标签、分叉回溯、分享。

**详解**：[会话管理](session.md)

## 8. 文件管理

浏览和管理项目目录里的文件：看、搜、传、复制、删除。

**详解**：[文件管理](file-manager.md)

## 9. 文件查看与编辑

打开单个文件后能做什么：不同类型的文件用不同方式看，代码还能直接改。

**详解**：[文件查看与编辑](file-viewer.md)

## 10. 标注与跳转系统

自动把聊天里出现的路径、commit、端口变成可点击的链接，点一下就跳过去。

**详解**：[标注与跳转系统](annotation.md)

## 11. Git 管理

查看当前项目的提交历史、分支、标签、工作树和未提交改动。

**详解**：[Git 管理](git.md)

## 12. 终端

服务器上的真实命令行，可开多个标签，并支持主题与虚拟键。

**详解**：[Web 终端使用指南](TERMINAL.md)

## 13. 任务

让 AI 按时间或事件自动干活：定时执行，或仓库有新动态时自动跑。

**详解**：[任务](tasks.md)

## 14. 数据统计

看用量、代码量、系统资源的数字面板。

**详解**：[数据统计](stats.md)

## 15. 设置

所有配置项的入口，按分类排列。

**详解**：[设置](settings.md) · [语音朗读（TTS）](TTS.md) · [会话搜索（RAG）](RAG.md)

## 17. 多项目与 Worktree

**详解**：[多项目与 Worktree](projects.md)（含设置 → 项目的项目注册表管理：查看会话数与最后活跃、切换、删除项目数据）

## 19. 多线并行工作方式

一个人同时推进多条开发线：思维转变、多会话 / 多 Worktree / 多项目、上下文投喂与并行纪律。

**详解**：[多线并行工作方式](parallel-workflow.md)

## 20. 推送通知

## 21. 常见问题

## 22. 部署与访问

## 23. 桌面客户端
