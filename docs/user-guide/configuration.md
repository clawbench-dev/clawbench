# 配置手册

> 这一篇不教功能怎么用，只回答一件事：**想改某个东西，去哪儿改、默认是什么、改完什么时候生效**。功能本身的用法见各章详解；每个设置项在界面上长什么样、点哪里，见 [设置](settings.md)。

## 先看这一节：配置分三层

| 层 | 存在哪 | 谁受影响 | 怎么改 |
|---|---|---|---|
| **服务端配置** | 数据目录里的 `config.yaml` | 连这台服务器的**所有设备** | 设置面板（绝大多数项）或直接改文件 |
| **服务器数据** | 数据库 `ClawBench.db` | 连这台服务器的所有设备 | **只能在界面里改**（智能体、模型提供商、邮箱账号、会议中继…） |
| **本机偏好** | 浏览器 / App 自己的本机存储 | **只有这台设备** | 只能在设置面板里改，换设备不会跟过去 |

一个容易误会的地方：**设置面板里改的绝大多数项，写的就是 `config.yaml`**。所以「在界面里点」和「手改文件」是同一份配置，不是两套——界面只是把文件内容画成了开关和输入框。

另一件容易误会的事：**不是所有能配置的东西都在 `config.yaml` 里**。智能体、模型提供商的密钥、邮箱账号、会议中继这些存在数据库里，`config.yaml` 里找不到它们，只能从界面改（也**不要**去手改数据库）。

### 改完什么时候生效

| 改什么 | 生效时机 |
|---|---|
| 设置面板里绝大多数项 | 保存后立刻生效，下一轮对话或下一次请求就用新值 |
| **HTTPS 证书目录** | 要重启（HTTPS 监听器在启动时创建） |
| 端口、监听地址、日志级别、日志保留天数、开发代理端口 | **只能改文件**，改完重启 |
| 手改 `config.yaml` 的任何一项 | 重启后生效 |
| 智能体的系统提示 | 下一轮对话，或它下次压缩上下文之后；不放心就新建一个会话 |
| 智能体的 ACP 启动命令 | 保存时会自动重连该智能体，下一轮用新命令 |

## 一、服务端配置文件 `config.yaml`

### 文件在哪

默认在 `~/.clawbench/config/config.yaml`。启动时按这个顺序找：

1. `<数据目录>/config/config.yaml`
2. 当前工作目录下的 `config/config.yaml`

数据目录默认是 `~/.clawbench`，可以用启动参数 `--data-dir` 换到别处（见下一节）。

几点要注意：

- **没有这个文件也能跑**。所有项都有默认值，零配置启动是正常状态，`config.yaml` 是可选的增强。
- **没配密码时会自动生成一个**，写在数据目录的 `auto-password` 文件里，启动时也会打印出来。想用固定密码，就在 `config.yaml` 里写 `password`，或者用「设置 → 安全 → 修改密码」。
- 文件里有 API Key、令牌、密码哈希，所以权限是 `0600`（只有运行服务的用户能读）。
- **在界面里改任何一项，整个文件会被重写**，你手写的注释不会保留。想留注释就别在界面里改，或者改完自己补回去。
- 手改文件后**必须重启服务**。改坏了也别慌：启动时解析失败会报错退出，文件还在，改回去就行。

### 服务与访问

| 字段 | 默认 | 说明 |
|---|---|---|
| `port` | `20000` | 服务端口。启动参数 `--port` 和环境变量 `PORT` 都能覆盖它，优先级见下一节 |
| `host` | 空 | 监听地址。留空＝所有网卡都能访问；写 `localhost`＝只有本机能访问（公网机器想只自己用就写这个） |
| `password` | 空 | 访问密码。留空＝自动生成；也可以写 `sha256:<哈希>`，界面改密码写的就是这种形态 |
| `default_agent` | 空 | 新会话默认用哪个智能体。留空＝列表里第一个可用的 |
| `language` | `zh` | 后台文案语言（推送、定时任务、自动继续这些没有页面上下文的场合用）。前端切换语言时会自动同步，一般不用手改 |
| `log_level` | `info` | 日志级别：`debug` / `info` / `warn` / `error` |
| `log_max_days` | `7` | 服务端日志保留几天，按天分文件 |
| `dev_port` | `0` | 本机开发代理端口（只监听 127.0.0.1）。`0`＝开了 HTTPS 时自动用「主端口 + 2」；`-1`＝关闭。开发时配合 `./dev-server.sh` 用，平时不用管 |

### HTTPS 证书 `tls`

| 字段 | 默认 | 说明 |
|---|---|---|
| `cert_dir` | `<数据目录>/config/tls` | 证书目录。**目录里有能认出来的证书对就自动走 HTTPS**，不需要额外开关。改完要重启 |

目录里认这三种文件名组合：`fullchain.pem` + `privkey.pem`、`cert.pem` + `key.pem`，或合并的单文件 `combined.pem`。都找不到就回退 HTTP。

> 界面入口：设置 → 安全 → HTTPS 证书，可以一键生成自签名证书、看它覆盖了哪些地址、什么时候到期。
>
> `tls` 下面还有 `enabled` / `cert_file` / `key_file` 三个旧字段，只为兼容老配置而保留，现在不生效，不用管。

### 端口映射 `port_forward`

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | 恒为 `true` | SSH 监听器始终开启。没有总开关——监听器在服务端、传输方式在客户端，任何一个值都没法同时服务所有客户端 |

|---|---|---|

| `idle_timeout` | `0` | 没有连接后多久回收会话，写成 `10m` 这种时长。`0`＝不回收 |
| `buffer_lines` | `2000` | 回放缓冲保留多少行 |
| `max_line_bytes` | `65536` | 单行最多多少字节，防止一行把内存吃光 |
| `max_buffer_mb` | `4` | 整个缓冲最多占多少 MB |
| `max_sessions` | `10` | 同时最多几个终端会话 |

> 界面入口：设置 → 终端（`max_line_bytes` / `max_buffer_mb` 两项只能改文件）。

### 推送通知 `push_mode` / `dingtalk` / `feishu` / `wechat`

| 字段 | 默认 | 说明 |
|---|---|---|
| `push_mode` | `native` | 往手机和 IM 发消息走哪条：`native`（原生推送）/ `dingtalk` / `feishu` / `wechat` / `disabled`（全关） |
| `dingtalk.app_key` / `app_secret` / `agent_id` | 空 | 钉钉企业应用的凭据 |
| `dingtalk.users` | 空 | 单聊推送的 userId 列表 |
| `feishu.app_id` / `app_secret` | 空 | 飞书企业应用凭据 |
| `feishu.users` | 空 | 单聊推送的 open_id 列表 |
| `wechat.bot_token` / `bot_id` / `base_url` / `user_id` | 空 | **扫码登录后自动写入**，不是手填的；令牌只写不回读 |

`dingtalk.enabled` / `feishu.enabled` 不用手写——服务端每次启动都按 `push_mode` 重新推导，手写的值会被覆盖。

> 界面入口：设置 → 推送通知。**「推送方式」和「浏览器系统通知」是两回事**：前者管手机和 IM，后者管网页最小化时的系统通知，想彻底静音两处都要关。

### 文件搜索 `file_search`

| 字段 | 默认 | 说明 |
|---|---|---|
| `display_limit` | `100` | 文件搜索最多显示多少条（10–500） |

### MCP 服务 `mcp.servers`

给所有走 ACP 的智能体共用的外部工具服务列表。每条：

| 字段 | 说明 |
|---|---|
| `name` | 服务名，也是发给智能体的名字。**改名会让引用了旧名的智能体策略失效** |
| `transport` | `stdio` / `http` / `sse` |
| `command` / `args` / `env` | 仅 `stdio`：命令、参数、环境变量 |
| `url` / `headers` | 仅 `http` / `sse`：地址与请求头（通常放认证令牌） |

### 智能体进程环境 `shell_env`

| 字段 | 默认 | 说明 |
|---|---|---|
| `inherit` | `false` | 是否把 shell 启动文件（`.bashrc` / `.zshrc`）里 export 的变量交给 AI 进程。默认关，因为要拿到这些变量就得真的执行那些文件，里面常有代理和令牌 |

### 壁纸 `appearance`

壁纸**选哪张、开不开**是每台设备自己的事，存在浏览器里，不在这个文件里。这里只有服务端必须管的两块东西，而且都**不要手改**——记的名字和磁盘上的文件是配对的：

| 内容 | 说明 |
|---|---|
| 本地上传的图库清单 | 每张图记着文件名、原始文件名、上传时间、大小；图片本身在 `<数据目录>/theme/local/` |
| Bing 每日图缓存 | 记着缓存文件名、署名、标题、上次抓取日期和上次的错误。抓取失败会保留上一张能用的图 |

> 这两块分别由界面上的「上传壁纸」和每日抓取自动写入。

## 二、启动参数与环境变量

| 参数 | 作用 |
|---|---|
| `--port <端口>` | 服务端口，优先级最高 |
| `--data-dir <目录>` | 数据目录，默认 `~/.clawbench` |
| `--gen-cert` | 生成自签名 HTTPS 证书后退出，下次启动即生效 |
| `--host <地址列表>` | **只配合 `--gen-cert` 用**：额外把哪些 IP / 域名写进证书，逗号分隔（比如办公室固定 IP） |
| `--version` | 打印版本号后退出 |
| `--help` / `-h` | 打印帮助后退出 |

端口的三层优先级：`--port` > 环境变量 `PORT` > `config.yaml` 的 `port` > 默认 `20000`。

其他环境变量都是给被调用的外部工具用的（比如 `HOME`、`PATH`、`SHELL`），不是 ClawBench 自己的配置项。

> 还有一个内部子命令 `upgrade-replace`，是自升级时由程序自己调用的，正常不用碰。

## 三、数据目录

默认 `~/.clawbench`，可以用 `--data-dir` 换地方。备份就备份这个目录。

| 文件 / 目录 | 用途 | 能删吗 |
|---|---|---|
| `ClawBench.db` | **全部业务数据**：会话、消息、智能体、任务、模型提供商、邮箱账号、通知、分享记录、会议记录 | 删了等于全部清空 |
| `ClawBench.db-wal` / `-shm` | 数据库的运行时文件 | 随主库一起备份；不要单独删 |
| `config/config.yaml` | 服务端配置 | 删了回到默认配置（密码会重新生成） |
| `config/agents/*.yaml` | 手写的智能体定义，启动时读进数据库 | 一般用不到；删了不影响数据库里已有的智能体 |
| `config/tls/` | HTTPS 证书 | 删了就回退 HTTP |
| `logs/clawbench-日期.log` | 服务端日志，按天分文件 | 可以，保留天数由 `log_max_days` 决定 |
| `logs/client.log` | 前端 / App / 桌面端回传的日志，行首 `[js]` `[android]` `[electron]` 区分来源 | 可以；要开「设置 → 调试 → 调试日志捕获」才会有内容 |
| `fonts/` | 自定义字体 | 可以，界面上那几个字体选项会失效 |
| `theme/local/` `theme/bing/` | 壁纸图库与 Bing 每日图缓存 | 可以，壁纸会没了 |
| `skills/` | 从 Git 拉下来的技能仓库 | 可以，下次同步会重新拉 |
| `providers/config-state.json` | 托管式提供商配置（如 Codex）的写入状态，用于解绑时还原 | **别手改** |
| `mail/attachments/` `mail/outbox/` | 邮件附件缓存与待发件 | 可以，附件要重新下载 |
| `vendor/drawio/<版本>/` | 按需下载的 draw.io 编辑器 | 可以，下次打开 `.drawio` 时重新下 |
| `auto-password` | 没配密码时自动生成的密码 | 删了会重新生成一个新密码 |
| `cookie-token` | 登录态令牌 | 删了所有设备都要重新登录 |
| `ssh_host_key` | SSH 隧道服务器的主机密钥 | 删了客户端要重新接受一次指纹 |
| `self-path` | 记录正在运行的二进制在哪，升级和重启用 | 删了会自动重新写 |
| `.instance.lock` | 单实例锁，进程退出自动释放 | **不要手删**，它保证一个数据目录只跑一个服务 |

> **上传的附件不在数据目录里**：聊天里传的文件放在**项目目录**下的 `.clawbench/uploads/`，跟着项目走。

> **一个数据目录只能跑一个服务**。同一个数据目录起第二个实例会等 10 秒后拒绝启动——不是抢端口，是两个实例共用一个数据库会互相破坏（启动恢复会把对方正在跑的回合当成「上次崩溃」重写掉）。

## 四、不在 `config.yaml` 里的配置

这些东西存在数据库里，只能从界面改，`config.yaml` 里没有对应字段：

| 配置 | 在哪改 | 说明 |
|---|---|---|
| 智能体（名称、头像、模型、系统提示、禁用、项目范围、MCP 策略） | 设置 → 智能体 | 启动时会自动扫描已装的 AI CLI 补进来 |
| 模型提供商（端点、密钥、模型清单） | 设置 → 模型提供商 | 密钥只写不回显；被智能体或摘要模型引用时不能删 |
| 邮箱账号 | 设置 → 邮箱账号 | 属于这台服务器，所有客户端共用 |
| 会议中继（LiveKit 地址与密钥） | 设置 → 视频会议 → 中继服务 | 全服务器共用一份，填完要「保存并测试连接」 |
| 项目列表 | 设置 → 项目 | 项目以内部编号为身份，改路径不会丢历史数据 |
| 定时 / 事件任务 | 任务页签 | 属于当前项目 |
| 分享链接 | 分享中心 | 链接里的 token 就是访问凭证 |
| 会话与消息 | 聊天 | —— |

## 五、只存在本机的偏好

这些**每台设备各存一份**，换设备、换浏览器都不会跟过去，也不会上传服务器。想两台设备一样，得各自设一遍。

| 分组 | 包含哪些 |
|---|---|
| 外观 | 主题、语言、界面缩放、是否自动适配、顶栏快捷键提示、布局记忆方式、表格与代码块默认换行、代码字体与备选、界面字体与备选、壁纸（开关 / 来源 / 选的哪张）、面板不透明度、模糊强度、动态波浪速度 |
| 聊天显示 | 消息显示模式（混合 / 仅摘要 / 仅原文）、自动朗读、防止锁屏、滑动切换会话、代码链接预览 |
| 文件 | 显示隐藏文件、默认视图（列表 / 网格）、排序字段与方向、自动换行、行号、粘性滚动、文件预览模式、最近文件数量 |
| 终端 | 配色主题、字号、选中即复制 |
| 会议 | 新会议默认勾选项（听记 / 关键画面 / 允许观众发言 / 允许成员共享屏幕）、画面与摄像头的分辨率 / 帧率 / 码率、画质自动降级 |
| 通知 | 应用内完成通知、通知提示音、浏览器系统通知、悬浮状态窗、实时更新 |
| 调试 | 调试日志捕获、信任的证书列表 |
| 其他 | 是否显示欢迎页、首次使用引导状态、会话列表是否显示其他项目 |

> **语言是个例外**：它按设备保存，但每次切换都会同步给服务端，打开应用时也会对齐一次，用于后台推送和定时任务的文案。所以服务端的 `language` 通常不用手改。

## 七、几个常见改法

### 换个端口

```bash
./clawbench --port 8080
```

想固定下来就写进 `config.yaml`：

```yaml
port: 8080
```

### 只允许本机访问

```yaml
host: localhost
```

公网机器上先这样用，等 HTTPS 和密码都配好了再放开。

### 设一个固定密码

```yaml
password: 你想要的密码
```

也可以留空让系统生成，密码会存在数据目录的 `auto-password` 里。忘了密码就去看那个文件。

### 开 HTTPS

最省事的是界面：设置 → 安全 → HTTPS 证书 → 生成自签名证书，然后按提示点「立即重启」。命令行等价做法：

```bash
./clawbench --gen-cert
```

### 临时关掉某个功能

```yaml
mail:
  enabled: false      # 停后台收信、隐藏邮件页签，账号保留
forge:
  enabled: false      # 停轮询、解除仓库绑定（重新打开不会自动恢复）
terminal:
  enabled: false      # 隐藏终端
```

关掉之后要重启才生效。
