# 邮件

> 本文同时适用于桌面端与移动端；两端差异处用 **桌面端** / **移动端** 标注。

ClawBench 里内置了一个邮件客户端：配一次邮箱账号，就能在同一个界面收信、看信、回信、写信，不用再开别的网页。它是左栏 Dock 上的「邮件」页签。

> 邮件是**全局**的，不属于某个项目——邮箱属于人，所以切到哪个项目看到的都是同一个收件箱。

## 先配一个邮箱账号

打开 **设置 → 邮件 → 邮箱账号**，点添加：

| 填写项 | 说明 |
|---|---|
| **邮箱服务商** | 选常见服务商（QQ、163、Gmail 等）会自动填好服务器地址；自建服务器选「自定义」 |
| **邮箱地址** | 完整地址，例如 `you@example.com` |
| **密码 / 授权码** | 大多数邮箱**不能用登录密码**，见下方说明 |
| **显示名称** | 可选，只是给自己看的备注 |
| **收信 / 发信服务器** | 选服务商时自动填；自定义时要手填地址、端口与加密方式（SSL/TLS、STARTTLS、不加密） |

填完点 **「保存并测试连接」**——它会真的连一次，通过了才算配好。

> **授权码怎么来**：QQ / 163 / 126 要先在网页版邮箱的「设置 → 账户」里开启 IMAP/SMTP 并生成**授权码**，这里填授权码；Gmail / Outlook / iCloud 要先开两步验证，再生成**「应用专用密码」**。直接填登录密码通常会报「邮箱登录失败」。
>
> **自签名证书的自建服务器**可以打开「跳过证书校验」，公共邮箱不要开。

## 界面

**桌面端**宽屏时，左侧是邮件列表，右侧是阅读 / 写信，中间的分隔条可以拖，比例会记住。**移动端**和窄窗口是逐层下钻：点一封邮件，整块换成阅读页，左上角「返回列表」。

面板顶部从左到右：

- **账号头像**：22dp 的圆形字母头像，悬停才显示完整邮箱地址；**只有一个账号时不显示下拉箭头**（没得选，箭头是假承诺）
- **当前位置**（文件夹）：图标 + 文件夹名 + 未读徽章。这一栏天天在用，所以做成导航的样子（无描边，悬停才浮出浅底），而不是和账号一样重的描边方框；未读数也不再塞进「收件箱 (12)」这种括号里
- **搜索框**：在当前已缓存的邮件里搜主题、发件人和摘要
- **全部已读**：把整个文件夹标为已读
- **收信**：立刻同步一次（后台本来每 3 分钟也会自动收一次）。同步期间图标转圈、完成后打勾，期间不能重复点
- **写邮件**：进入写信页

两个下拉菜单也同步重做：文件夹菜单顶部标出当前账号，每行是「图标 + 名称 + 右对齐计数」，当前项打勾；账号菜单显示「头像 + 地址 + 账号名」。

**列表行**分三层：发件人、主题、摘要；未读的主题是加粗的，时间分两行显示（友好日期 + 精确时分），附件和星标跟在主题后面。

## 读一封邮件

点开一封邮件，顶部是操作条：**回复 / 全部回复 / 转发 / 星标 / 标为已读（或未读）/ 删除**。

- **外部图片默认不加载**——邮件里的追踪像素就是这样工作的。顶部会出现「外部图片已拦截」，点 **「显示图片」** 才加载这一封的外部图片
- **附件**列在正文下方，点一下即可下载
- 手机上看过的邮件，同步后在这里也会变成已读（两边状态会互相追）

## 写邮件

点「写邮件」进入写信页：

- 填收件人，需要的话展开「添加抄送 / 密送」
- 填主题、正文，可以「添加附件」
- 点「发送」

发送成功后会自动往「已发送」里放一份（放不进去也不影响已经发出去这件事）。**草稿只存在本地**——关掉页面再回来还在，但不会同步到你邮箱的「草稿箱」文件夹。

从某封邮件点「回复 / 转发」进来时，收件人、主题前缀、引用正文都已经填好；这时按返回会回到那封邮件，而不是直接回列表。

## 用邮件触发任务

任务可以选「邮件触发」：指定一个邮箱（和可选文件夹），再配几个条件——发件人包含、主题包含、正文包含、必须带附件。**全部满足**的新邮件会自动跑一次 AI 回合。

- 只对**任务保存之后新到**的邮件生效，配置前就在收件箱里的不会触发
- 同一封邮件对同一个任务只触发一次
- 单次收信每个任务最多触发 5 次，避免一次收到上百封就起上百个回合

详见 [任务](tasks.md)。

## 关掉邮件功能

**设置 → 邮件 → 邮件总开关**（默认开）。关掉后：

- 后台不再连邮箱服务器，邮件触发的任务也停下
- 左栏「邮件」页签隐藏
- **账号和已收的邮件都保留**，重新打开就从原处继续

这个开关存在服务器上，所以同一台服务器的所有设备表现一致——它不是某台设备上的显示偏好。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示「邮箱登录失败」 | 多半是填了登录密码。改用授权码 / 应用专用密码，并确认邮箱网页版里已开启 IMAP |
| 提示「连不上邮件服务器」 | 服务器地址或端口不对；公司/学校邮箱可能需要内网或 VPN |
| 提示「证书校验失败」 | 自建服务器用了自签证书，打开该账号的「跳过证书校验」 |
| 提示「这个邮箱正在同步中」 | 上一次同步还没结束，等几秒再点「收信」 |
| 收不到新邮件 | 确认总开关是开的、账号没被禁用；后台每 3 分钟同步一次，也可以手动点「收信」 |
| 图片显示不出来 | 默认拦截外部图片，点邮件顶部的「显示图片」 |
| 发出的邮件在「已发送」里没有 | 邮箱服务器不允许客户端追加到已发送；邮件本身已经发出去了 |
