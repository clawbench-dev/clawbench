# 知识库

把文件变成「能问的资料」：建几个库，把文档丢进去，之后聊天时 AI 会自动翻到相关内容，回答后面还会标出引用了哪几段。

左栏 Dock 的 **知识库** 页签就是入口。

> **它和「会话搜索」不是一回事**：会话搜索回答「我们以前聊过什么」，知识库回答「资料里是怎么写的」。两套索引完全分开，搜会话时不会混进知识库的文件，反之也一样。

## 建一个知识库

点「新建知识库」，填名称（比如「公司制度」「产品资料」）和一句说明，再选**归属**：

| 归属 | 谁能看到 |
|---|---|
| **全局** | 任何项目都能看到、也能被检索 |
| **当前项目** | 只在当前项目可见 |

项目级知识库跟着项目走：切到别的项目，它就从这个页签里消失，不会被别的项目拿去参考。

建好之后可以随时**改名或改说明**（库标题右边的铅笔按钮）。**归属不能改**：换归属会让整库文件在别的项目里突然出现或消失，风险比收益大。

库行右侧的图钉可以**置顶**，置顶的库在所属分组里排最前。库多了用列表上方的筛选框按名字找，也可以按「最近添加 / 名称」排序。

## 加文件

选中一个知识库，点「添加文件」。可以一个一个挑，也可以**直接选一个文件夹**，整棵子树一次性导入。

- 支持文本与 Markdown、网页（`.html`）、PDF、Word（`.docx`）、Excel（`.xlsx`）、PowerPoint（`.pptx`）
- 单文件上限默认 50MB，文字超过约 20MB 的部分会被截断，并在文件上标注
- 一次选文件夹最多导入 500 个文件；重复的文件会跳过，不会加第二份
- **选文件夹后会先给一个预览**：「将加入 N 个，跳过 N 个，重复 N 个，失败 N 个」，确认后才开始复制
- 导入完会给一句小结：「加入 N 个，跳过 N 个，重复 N 个，失败 N 个」

**文件管理器里也能加**：右键文件或文件夹，点「加入知识库」，选一个库（或顺手新建一个）即可。选文件夹同样先给预览，确认后开始导入。

另外三个快捷入口：

- 工具栏的「**粘贴文本**」：直接写一段笔记，不必先存成文件
- 工具栏的「**从链接添加**」：贴一个网页地址，抓取正文后入库（最多 20MB）
- 从文件管理器把文件或文件夹**直接拖进知识库面板**

**文件是复制进来的**，不是引用原路径。删掉或移动原文件不影响知识库；反过来删知识库也不会动你的源文件。

## 索引状态

文件加进去后，后台会解析文字、切段、建索引。每个文件后面标着当前状态：

| 状态 | 意思 |
|---|---|
| 排队中 | 等索引器来取 |
| 解析中 | 正在抽文字 |
| 可搜索 | 关键词与语义都能搜到 |
| 仅关键词 | 语义索引还没算完（或嵌入服务不可用），关键词搜索照常能用 |
| 失败 | 解析不了（加密 PDF、损坏文件等），点开看原因 |

语义索引是分批算的，所以一个刚加进来的大文件可能先是「仅关键词」，过一会儿自己变成「可搜索」。**关键词检索始终可用**，嵌入服务挂了也不影响基本搜索。

库标题下面有一行健康信息，比如「12 个文件 · 1 个失败 · 2 个处理中」。**点这些数字就是筛选**：点「1 个失败」只看失败的文件，再点一次恢复。左侧库列表也会给有问题的库标上同样的数字，不用逐个点进去找。

失败的文件点开就能看到**人话原因**（比如「没有可提取的文字，可能是扫描件」），不用去翻服务端日志。

文件行还会标出两种和原文件有关的状态：**「原文件已更新」**（原文件比库里的副本新，点开详情用「用原文件更新」同步）和**「原文件不在了」**（被移走或删除，副本仍可用但不能再同步）。

索引是后台跑的，**你可以放心切走**。整批处理完会弹一条提示（有失败会带上失败数），不用守着面板。

## 搜一下

搜索框常驻在库列表上方，**不用先点进某个库**也能搜。右边两档：

- **混合**：关键词 + 语义一起排，问法不必和原文一致
- **关键词**：只按字面匹配，适合查编号、专有名词

**边打边搜走关键词**（快、不用等），**按回车走你选的模式**（默认混合）。范围可以选「全部」或「当前库」——没选库时「当前库」不可用。

每条结果都标出**来自哪个库**、命中在文件的什么位置（第几页 / 第几行 / 哪个工作表第几行）。**点结果会打开文件详情**，并定位到命中的那一段，方便你回去对原文。结果条数写的是「前 N 条」，不是命中总数。

如果搜索框下面提示「当前仅关键词检索」，说明没有配置语义索引（或索引还没算完）。这时混合模式会退化成关键词，界面会照实说明，不会假装是混合结果。

## 看文件解析成了什么

点任意文件行，会打开**文件详情**：

- 这份文件被切成了哪些段，每段的页码 / 行号 / 工作表位置
- 原文件路径（同名文件靠它区分）
- 失败原因、文字截断提示
- 单文件重建、删除

从搜索结果点进来时，命中的那一段会高亮；聊天引用点进来时也一样。

每段右上角有「**引用到聊天**」：点它会把这一段放进聊天输入框，并带上文档名和位置，接着追问就行。

文件详情里还能：

- **打标签**：填「制度, 报销」这样的逗号分隔标签，列表上会显示，也能按标签筛选
- **看使用情况**：这个文件被聊天引用过几次、最近一次是什么时候（只有真的被检索带进对话才计数）

## 批量管理

点工具栏的「选择」进入多选：点文件行是勾选，不会再打开详情。可以「全选」当前筛出来的文件，然后批量**重建**、**删除**（只弹一次确认）或**移动到另一个知识库**。

列表上方还能按**类型**筛选（PDF / Word / Excel / PPT / 文本）、按**标签**筛选，按**最近添加**或**名称**排序。文件超过 100 个时先显示一页，点「显示更多」继续加载。

## 聊天时自动参考

这个能力默认是关的，先在 设置 → 知识库 里打开「**自动注入知识库内容**」（总开关）。然后打开一个知识库，顶部工具栏右侧还有「**聊天检索**」开关（默认开），可以按库单独关掉。两处都开着的时候，你发一条消息，服务端会先去相关库里找几段最贴近的内容，一起交给 AI，所以回答会带着你的资料说话。

- **每轮最多带 4 段、2000 字**，不会把整个库塞进上下文
- 只带真的相关的：纯语义命中的相似度低于 0.35 就不带，宁可不参考也不硬凑
- 检索有 **1.5 秒预算**，超时或出错就跳过，不会拖住你的对话
- 群聊里只按**第一位发言人**的问题去检索一次，之后大家共用这批片段

回答气泡底部、文件变更下面会出现「**参考了知识库 · N 段**」，点开能看到每段来自哪个库、哪个文件，方便核对 AI 有没有瞎编。每段下面有「**在知识库中查看**」，点它直接跳到知识库面板并打开那份文件（新消息会定位到命中的那一段）。

**反过来也能存**：回复下方的「**存为知识**」按钮，把这条回答变成一篇 Markdown 笔记放进知识库——选现有库或就地新建。存进去之后它和普通文件一样参与检索，下次聊天就能用上。

## 重建索引

- **单个文件**：文件行右侧的「重建索引」按钮，重新解析这一个文件
- **整个库**：顶部工具栏的「重建索引」按钮，把库里全部文件重跑一遍（文件多时要等一会儿）

什么时候需要重建：**换了嵌入模型之后**（向量维度和含义都变了，旧索引作废）。

**原文件改了怎么办**：打开文件详情，点「**用原文件更新**」。它会重新读原文件、比对内容——没变就只提示「没有变化」，变了才替换副本并重建索引。原文件已经被移走或删掉时会明确提示，知识库里的副本不受影响，照样能搜。

> 注意：「重建索引」读的是知识库里的副本，不会去读原文件；要把原文件的新内容带进来，用「用原文件更新」。

## 删除

- **删文件**：这个文件的索引和副本一起删掉。删完的提示可以点一下**撤销**——前提是原文件还在，会从原文件重新加入（不是恢复旧副本，原文件改过就是新内容）
- **删知识库**：库里全部文件、索引、副本一起删掉，不能恢复

源文件不受影响——删的只是知识库里的那份副本。

## 配置

服务端配置在 `config.yaml` 的 `kb` 段（见 [配置说明](configuration.md#知识库-kb)）。几个常用的：

| 配置 | 默认 | 作用 |
|---|---|---|
| `enabled` | `true` | 知识库总开关，关掉后页签消失、聊天也不再带片段 |
| `auto_inject` | `false` | 聊天自动参考的总开关，默认关（打开后每个库还能单独关） |
| `inject_top_n` / `inject_max_chars` | 4 / 2000 | 每轮带几段、最多多少字 |
| `max_file_mb` | 50 | 单文件大小上限 |

嵌入服务复用 `rag` 段的地址、模型与密钥——知识库不单独配一套。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 文件一直「排队中」 | 索引器没在跑或嵌入接口不通；先看服务端日志，关键词索引不依赖嵌入，通常很快就能变成「仅关键词」 |
| 搜不到刚加的文件 | 还在解析；状态到「可搜索」或「仅关键词」之后才进检索 |
| 聊天没带知识库内容 | 先确认设置里的「自动注入知识库内容」已打开（默认关），再看这个库的「聊天检索」是否开着；问法和资料差太远时相似度不够也会不带 |
| 换了嵌入模型后搜不准 | 重建一次索引，旧向量不能混用 |
