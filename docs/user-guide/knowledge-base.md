# 知识库

把文件变成「能问的资料」：建几个库，把文档丢进去，之后聊天时 AI 会自动翻到相关内容，回答后面还会标出引用了哪几段。

左栏 Dock 的 **知识库** 页签就是入口。

> **它和「会话搜索」不是一回事**：会话搜索回答「我们以前聊过什么」，知识库回答「资料里是怎么写的」。两套索引完全分开，搜会话时不会混进知识库的文件，反之也一样。

## 建一个知识库

点「新建知识库」，填名称（比如「公司制度」「产品资料」）和一句说明，再选**归属**：

| 归属 | 谁能看到 |
|---|---|
| **全局** | 任何项目都能看到、也能被检索 |
| **当前项目** | 只在当前项目可见 |

项目级知识库跟着项目走：切到别的项目，它就从这个页签里消失，不会被别的项目拿去参考。

## 加文件

选中一个知识库，点「添加文件」。可以一个一个挑，也可以**直接选一个文件夹**，整棵子树一次性导入。

- 支持文本与 Markdown、网页（`.html`）、PDF、Word（`.docx`）、Excel（`.xlsx`）、PowerPoint（`.pptx`）
- 单文件上限默认 50MB，文字超过约 20MB 的部分会被截断，并在文件上标注
- 一次选文件夹最多导入 500 个文件；重复的文件会跳过，不会加第二份
- 导入完会给一句小结：「加入 N 个，跳过 N 个，重复 N 个，失败 N 个」

**文件是复制进来的**，不是引用原路径。删掉或移动原文件不影响知识库；反过来删知识库也不会动你的源文件。

## 索引状态

文件加进去后，后台会解析文字、切段、建索引。每个文件后面标着当前状态：

| 状态 | 意思 |
|---|---|
| 排队中 | 等索引器来取 |
| 解析中 | 正在抽文字 |
| 可搜索 | 关键词与语义都能搜到 |
| 仅关键词 | 语义索引还没算完（或嵌入服务不可用），关键词搜索照常能用 |
| 失败 | 解析不了（加密 PDF、损坏文件等），点开看原因 |

语义索引是分批算的，所以一个刚加进来的大文件可能先是「仅关键词」，过一会儿自己变成「可搜索」。**关键词检索始终可用**，嵌入服务挂了也不影响基本搜索。

## 搜一下

顶部搜索框，右边两档：

- **混合**：关键词 + 语义一起排，问法不必和原文一致
- **关键词**：只按字面匹配，适合查编号、专有名词

范围可以选「全部」或「当前库」。每条结果都标出**来自哪个库**、命中在文件的什么位置（第几页 / 第几行 / 哪个工作表第几行），方便你回去对原文。

## 聊天时自动参考

打开一个知识库，顶部工具栏右侧有「**聊天检索**」开关（默认开）。开着的时候，你发一条消息，服务端会先去相关库里找几段最贴近的内容，一起交给 AI，所以回答会带着你的资料说话。

- **每轮最多带 4 段、2000 字**，不会把整个库塞进上下文
- 只带真的相关的：纯语义命中的相似度低于 0.35 就不带，宁可不参考也不硬凑
- 检索有 **1.5 秒预算**，超时或出错就跳过，不会拖住你的对话
- 群聊里只按**第一位发言人**的问题去检索一次，之后大家共用这批片段

回答气泡下方会出现「**参考了知识库 · N 段**」，点开能看到每段来自哪个库、哪个文件，方便核对 AI 有没有瞎编。

## 重建索引

- **单个文件**：文件行右侧的「重建索引」按钮，重新解析这一个文件
- **整个库**：顶部工具栏的「重建索引」按钮，把库里全部文件重跑一遍（文件多时要等一会儿）

什么时候需要重建：**换了嵌入模型之后**（向量维度和含义都变了，旧索引作废），或者某个文件在原处被替换、你想让新内容生效。

## 删除

- **删文件**：这个文件的索引和副本一起删掉
- **删知识库**：库里全部文件、索引、副本一起删掉，不能恢复

源文件不受影响——删的只是知识库里的那份副本。

## 配置

服务端配置在 `config.yaml` 的 `kb` 段（见 [配置说明](configuration.md#知识库-kb)）。几个常用的：

| 配置 | 默认 | 作用 |
|---|---|---|
| `enabled` | `true` | 知识库总开关，关掉后页签消失、聊天也不再带片段 |
| `auto_inject` | `true` | 聊天自动参考的总开关（每个库还能单独关） |
| `inject_top_n` / `inject_max_chars` | 4 / 2000 | 每轮带几段、最多多少字 |
| `max_file_mb` | 50 | 单文件大小上限 |

嵌入服务复用 `rag` 段的地址、模型与密钥——知识库不单独配一套。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 文件一直「排队中」 | 索引器没在跑或嵌入接口不通；先看服务端日志，关键词索引不依赖嵌入，通常很快就能变成「仅关键词」 |
| 搜不到刚加的文件 | 还在解析；状态到「可搜索」或「仅关键词」之后才进检索 |
| 聊天没带知识库内容 | 确认这个库的「聊天检索」是开的、`kb.enabled` 与 `auto_inject` 也没关；问法和资料差太远时相似度不够也会不带 |
| 换了嵌入模型后搜不准 | 重建一次索引，旧向量不能混用 |
