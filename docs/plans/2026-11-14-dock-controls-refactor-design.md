# Dock 控制与排序重构设计

日期：2026-11-14
状态：待实现
范围：`web/src` 前端 Dock 与设置页；服务端新增任务、分享两个总开关
相关文件：[dockTabs.ts](../../web/src/composables/dockTabs.ts)、[useDockPlugins.ts](../../web/src/composables/useDockPlugins.ts)、[DockPluginSetting.vue](../../web/src/components/settings/DockPluginSetting.vue)、[App.vue](../../web/src/App.vue)、[settingsFieldMap.ts](../../web/src/components/settings/settingsFieldMap.ts)

## 0. 一句话

左栏所有页签排成一条可拖列表，管理器是唯一的开关入口；有后台功能的页签，一个开关同时管显示和后台；没有后台功能的只控显示；预设同时决定显示、顺序和开关。

## 1. 页签模型

左栏 14 个页签，聊天固定在右栏，不在左栏列表里。

| 类型 | 页签 | 显示开关 |
|---|---|---|
| 常驻 | 文件管理、文件浏览、通知中心、设置 | 灰显，不能隐藏 |
| 可选 | 历史、Forge、任务、终端、统计、邮件、知识库、会议、分享、端口映射 | 可开关 |

- 取消原来的「固定头」：文件管理、文件浏览、历史不再单独占顶部，全部进入同一条列表。
- 所有页签都能拖，包括常驻页签和设置。
- 分享中心可以隐藏，位置可拖；关掉后页签消失。

## 2. 开关模型

管理器里的开关分四种：

| 页签 | 开关作用 |
|---|---|
| Forge、邮件、终端、知识库、任务、分享 | 显示 + 后台 |
| 历史、统计、会议、端口映射 | 只控制显示（没有后台总开关） |
| 文件管理、文件浏览、通知中心、设置 | 灰显，不能关 |

有后台功能的页签，关掉后页签消失。

补充：

- 终端既有后台开关，又依赖这台机器能不能跑终端；环境不支持时，开关要灰显并写原因。
- 端口映射没有后台开关，只依赖环境；环境不支持时同样灰显并写原因。
- 所有后台开关都是服务端全局，不是每个项目、每台设备各一份。
- 开关文案要区分：有后台功能的写「启用」，只控制显示的写「在 Dock 中显示」，常驻的灰显写「常驻」。

后台开关对应的配置键：

| 页签 | 配置键 | 关掉后 |
|---|---|---|
| Forge | `forge.enabled` | 停轮询，清空所有项目的仓库绑定（不可恢复） |
| 邮件 | `mail.enabled` | 停后台收信和邮件触发任务，账号保留 |
| 终端 | `terminal.enabled` | 关闭所有已打开的终端会话 |
| 知识库 | `kb.enabled` | 停索引器、关库，数据保留 |
| 任务 | `tasks.enabled`（新增） | 停调度，并取消正在运行的任务 |
| 分享 | `share.enabled`（新增） | 撤销所有已经发出去的分享链接 |

模块自己的配置页不再放开关，只显示「已启用 / 已停用」和「去插件管理」入口。Forge、邮件、终端、知识库、任务、分享都按这个方式处理。

## 3. 预设

三个预设：**开发、办公、极简**。预设同时设置显示、顺序和后台开关。

### 开发

全部开启。顺序：

文件管理 → 文件浏览 → 历史 → Forge → 任务 → 终端 → 统计 → 邮件 → 知识库 → 会议 → 分享 → 端口映射 → 通知中心 → 设置

### 办公

隐藏 Forge、终端、端口映射；关掉 Forge、终端；邮件、知识库、任务、分享保持开启。顺序：

文件管理 → 文件浏览 → 历史 → 任务 → 统计 → 邮件 → 知识库 → 会议 → 分享 → 通知中心 → Forge → 终端 → 端口映射 → 设置

### 极简

只留常驻页签；关掉 Forge、终端、邮件、知识库、任务、分享。分享页签也会隐藏。顺序：

文件管理 → 文件浏览 → 通知中心 → 历史 → Forge → 任务 → 终端 → 统计 → 邮件 → 知识库 → 会议 → 分享 → 端口映射 → 设置

### 确认

应用「办公 / 极简」前先弹确认，列出会停掉什么、会撤销什么：

- Forge：清空仓库绑定；
- 终端：断开所有已打开的终端会话；
- 任务：取消正在运行和排队中的任务，恢复后不补跑；
- 分享：撤销所有已发出的链接，旧链接直接 404。

单个开关同样要确认：直接在管理器里关 Forge、终端、任务、分享，也会触发上面的后果，不能只给预设加确认。

取消确认则整个预设不生效。

## 4. 关闭后的入口联动

功能关掉后，不只是自己的页签消失，其他页面里做这件事的入口也要一起禁用。

原则：

- **动作入口**：按钮、右键菜单项直接隐藏或禁用，并在提示里写「功能已关闭」。
- **跳转入口**：点了要跳到这个功能页签的，拒绝跳转并提示「功能已关闭，去插件管理打开」。
- **历史内容**：任务卡片、邮件等历史内容仍然可读；分享是例外，关掉后旧链接直接 404。

分享关掉后要处理的入口：

- 文件管理器右键「分享链接」；
- 文件预览头部「分享链接」；
- 聊天输入栏「分享会话」；
- 会话列表右键「分享会话」；
- 会议详情 / 资源页「发布分享 / 停止分享」；
- 分享中心页签本身隐藏；如果它正开着，关掉后切走；
- 会话列表里的「已分享」徽标：分享关掉后清空。

邮件关掉后：

- 文件管理器右键「用邮件发送」；
- 文件预览头部「用邮件发送」。

终端关掉后：

- 文件管理器右键「在此打开终端」。

知识库关掉后：

- 知识库的新增按钮只在知识库页内；页签隐藏即可，没有外部入口。

任务关掉后：

- 聊天里的任务卡片、任务通知、补全弹窗里的任务跳转：禁止跳转并提示；
- 任务卡片本身仍显示历史信息；
- 排队中的任务取消，恢复后不补跑；手动运行也拒绝。

Forge 关掉后：

- Forge 通知跳转、聊天里的 Forge 引用卡片：禁止跳转并提示。

「分享到其他应用」是系统分享，不依赖分享中心，分享关掉后仍然可用；文件管理器的批量分享按钮也属于系统分享，保留。

会议、统计、历史、端口映射没有后台开关，只有显示开关；隐藏时沿用现有 `switchTab` 的拦截，不额外做入口联动。文件管理器的「Git 历史」按钮要在历史页签隐藏时禁用或提示。

## 5. 分类与命名

- 设置分类 `dockPlugins` 的显示名：`插件与 Dock` → `功能编排`。
- Dock 页签：`文件管理器` → `文件管理`，`文件` → `文件浏览`。
- 设置分类：`文件` → `文件管理`，`文件预览` → `文件浏览`。
- 设置分类：`邮箱账号` → `邮件`。
- 新增一级分组「模型能力」，把模型提供商、RAG 检索、语音朗读、语音识别从「AI 与对话」移进去。
- 内部 id（`files`、`fileView`、`mail`、`rag`）不变，只改显示名。

### 5.1 聊天拆成两个页面

现在的「聊天」混了会话列表、会话生命周期、消息展示和聊天行为，拆成「聊天」和「会话管理」两个独立页面，会话管理排在聊天后面。

**会话管理**（新分类 `sessions`）

- 会话列表：最大会话数、会话按最近活动排序、滑动切换会话、其他项目卡片上限、活跃窗口（小时）、其他项目会话的展示方式（常驻条 / 底部页签）。
- 会话生命周期：异常终止自动继续、最大重试次数、重启恢复时间窗（分钟）、AI 自动命名会话、摘要模型（自动命名用）、自动清理归档会话、留存天数。
- 会话搜索与索引：RAG 索引保留天数、搜索结果数、搜索池大小、批大小。

**聊天**（保留 `chat`）

- 交互：朗读、输出期间不锁屏。
- 消息展示：消息展示模式、收起工具调用、初始消息数、每页消息数。
- 上下文：系统提示间隔、分支/回溯历史上限。
- 推荐回复：推荐回复、参考消息数、摘要模型（推荐回复用）。
- 群聊：智能体讨论次数上限。

两个页面都用普通字段列表，不需要自定义页面。摘要模型出现两次，是同一个共享模型，但分别跟着自动命名和推荐回复。

### 5.2 设置页顺序

一级分组从上到下：

1. **项目与外观**：项目、外观、功能编排、文件管理、文件浏览、Git 历史、统计。
2. **AI 与对话**：身份与偏好、聊天、会话管理、智能体、任务、技能、MCP、知识库、会议。
3. **模型能力**：模型提供商、RAG 检索、语音朗读、语音识别。
4. **连接与集成**：终端、端口映射、邮件、分享中心、GitHub/GitLab 集成。
5. **通知与安全**：推送通知、通知中心、用量、安全。
6. **系统与关于**：调试、关于。

说明：

- 「会话管理」紧跟在「聊天」后面。
- 「模型能力」是独立的一级分组，排在「AI 与对话」后面。
- 「会议」留在「AI 与对话」，不跟语音设置一起搬走。
- 「知识库」留在「AI 与对话」，不跟 RAG 检索一起搬走。

### 5.3 新增四个配置页

**Git 历史**（`gitHistory`，放在「项目与外观」）

- 每页提交数：现在固定 30 条，需要后台支持。
- 默认隐藏合并提交：现在默认显示，本地设置即可。
- 提交时间显示：相对时间 / 绝对时间，本地设置即可。
- 是否显示提交图：现在默认显示，本地设置即可。

**任务**（`tasks`，放在「AI 与对话」）

- 执行记录保留天数 + 自动清理：现在只能手动删，需要后台清理任务。
- 完成 / 失败通知开关：现在会自动生成通知，需要后台支持。
- 默认时区：cron 按哪个时区跑，需要后台支持。
- 任务列表默认筛选：全部 / 启用 / 暂停，本地设置即可。

**统计**（`stats`，放在「项目与外观」）

- 默认页签：用量 / 代码量 / Git 代码，本地设置即可。
- 默认时间范围：24 小时 / 7 天 / 30 天，本地设置即可。
- 记住上次选择：现在每次回到默认，本地设置即可。

**分享中心**（`share`，放在「连接与集成」）

- 允许分享文件 / 会话 / 会议：三类分别开关，需要后台支持。
- 文件分享是否允许下载：需要后台支持。
- 分享链接默认有效期：现在没有有效期，需要后台支持。
- 分享页是否显示来源项目名：需要后台和页面模板支持。

说明：分享中心的全局开关仍然在「功能编排」里；这个配置页只放更细的分享规则。


## 6. RAG 拆分

`rag` 面板现在混了三类配置，按下面的方式拆：

| 内容 | 去哪 |
|---|---|
| 运行状态 | 留在「RAG 检索」 |
| 保留天数、搜索结果数、搜索池、批大小 | 会话管理 |
| 自动注入、注入条数/字数/相似度、文件大小、轮询间隔、嵌入批大小 | 知识库配置 |
| 向量开关、嵌入地址、模型、密钥、分块大小/重叠 | 留在「RAG 检索」，标注「知识库共用」 |

`kb.enabled` 是管理器里的开关，不放在知识库页；知识库页只放其它 `kb.*` 配置。运行状态描述的是索引本身，留在「RAG 检索」；会话管理放影响会话检索行为的配置。知识库复用的就是最后这一组，所以不能只归给知识库；留在「RAG 检索」并写清楚两边共用，避免 RAG 页失去配置入口。

## 7. 迁移

- 老用户保存的 `dockOrder` 只包含原来的可拖部分。升级时用「默认顺序 + 老顺序里的相对位置」合并，不能简单追加到末尾，否则文件管理会跑到最后。
- 分享中心改回可隐藏后，老的 `dockHidden` 里如果有分享，继续生效。
- 预设 id 保持 `developer` / `standard` / `minimal` 不变，只改显示名，避免迁移。
- 新增 `tasks.enabled`、`share.enabled` 默认都为 true；老配置文件没有这两个键时按 true 处理。

## 10. 风险

- 预设会真的停服务、撤销链接、清空 Forge 绑定，确认框必须写清楚，且取消要整个预设不生效。
- 老顺序迁移不能把常驻页签甩到末尾。
- 分享改回可隐藏后，极简会关掉它并撤销链接，确认框要写清楚。
- 任务、分享是新后台开关，需要同时改配置、默认值、热更新和接口文档。
- 单个开关也会造成破坏性后果，确认不能只加在预设上。
- 服务端必须自己拦截，不能只靠前端藏入口。
- 预设要保证全成或全不成，否则会留下半套状态。
- 分享撤销要覆盖文件、会话、会议三类，不能只清文件分享。
- 拖拽排序没有键盘替代，这是已接受的取舍；如果以后要补，再加菜单或快捷键。
- 入口联动容易漏：分享有文件管理器、文件预览、聊天、会话列表、会议五处；邮件两处；终端一处。改动时要逐个核对。
- 文档也要同步：设计文档、插件开发文档、用户手册、设置页说明。

## 11. 已确认的决定

- 设置页名字：功能编排。
- 分享可以隐藏；极简会关掉分享并撤销链接。
- 旧分享链接直接 404。
- 任务关掉：取消运行中和排队中的任务，恢复后不补跑，手动运行拒绝。
- 不做键盘排序替代，只用拖拽。
- RAG 运行状态留在「RAG 检索」；会话检索行为配置移到会话管理。
- 聊天拆成「会话管理」和「聊天」，会话管理排在聊天后面。
- 新增 Git 历史、任务、统计、分享中心四个配置页。
- 「每页会话数」是死配置，已删除：配置字段、默认值、接口返回、前端状态和测试一起清掉。
- 「分享到其他应用」保留，只禁分享中心。

## 12. 实现补充

实现时确定的几个细节，后续维护按这里为准：

- `share.enabled=false` 会撤销已发布的文件/会话/会议链接；**正在进行的会议**的加入链接仍然有效，否则观众会被关在门外。会议结束后如果发布开关也被撤销，记录页才 404。
- `share.allow_files` / `allow_sessions` / `allow_meetings` 只拦**新建**，已有链接继续有效；要撤销已有链接用总开关 `share.enabled`。
- `share.allow_download=false` 只拦「下载原文件」；在线预览不受影响。目录分享的每个文件下载、分享中心的直链复制也一并禁用。
- `share.link_ttl_days` 只影响**新建**链接，已有链接保留创建时的有效期。
- `tasks.timezone` 用 IANA 名称；PATCH 会拒绝无效时区，启动时读到无效值会回落到服务器本地时区并打警告。
- `tasks.notify_on_success` / `notify_on_failure` 只影响新通知；历史通知不删。
- `statsRememberLast=true` 时，统计页签和时间范围会落盘，刷新后恢复；关闭开关不读写已存记录。
- `shareMetaResponse` 的下载字段 JSON 名是 `allowDownload`（Go 字段名 `DownloadAllowed`），不要 omitempty，否则 `false` 传不到分享页。
- Git 历史每页条数从 `git_history.page_size` 读；旧缓存条目在配置变更后最多 30 秒内可能仍是旧页大小。
