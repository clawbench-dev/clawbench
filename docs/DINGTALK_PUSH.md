# 钉钉机器人推送配置

ClawBench 支持通过钉钉机器人推送通知，AI 会话完成、权限审批、定时任务状态变更时即时收到消息。

---

## 配置步骤

### 1. 创建钉钉应用

1. 登录 [钉钉开放平台](https://open-dev.dingtalk.com/)
2. 点击 **创建应用** → 选择 **企业内部应用**
3. 填写应用名称和描述，创建完成后记录 **AppKey** 和 **AppSecret**

### 2. 开启机器人能力

1. 进入应用 → **应用功能** → **机器人**
2. 点击 **开启** 启用机器人
3. 消息接收模式选择 **Stream 模式**（无需公网回调地址）

### 3. 配置事件订阅

1. 进入 **事件与回调** → **事件配置**
2. 推送方式选择 **Stream 推送**（与机器人消息接收模式一致）

### 4. 权限配置

进入 **权限管理**，搜索并开通以下权限：

| 权限 | 权限标识 | 说明 |
|------|----------|------|
| 调用SNS API时需要具备的基本权限 | `snsapi_base` | 基本权限 |
| 调用企业API时需要具备的基本权限 | `qyapi_base` | 基本权限 |
| 企业内机器人发消息权限 | `qyapi_robot_sendmsg` | 发送单聊消息 |

### 5. 发布应用

1. **版本管理** → 创建版本 → 提交审核
2. 审核通过后发布
3. 在 **应用可见范围** 中添加需要使用推送的用户

### 6. 在 ClawBench 中配置

1. 打开 ClawBench 设置面板
2. 推送模式选择 **钉钉推送**
3. 填入 AppKey 和 AppSecret
4. 点击 **测试连接** 验证配置
5. 保存后自动生效

## 使用说明

### 订阅通知

在钉钉中向机器人发送任意消息即可自动订阅通知。订阅成功后会收到回复消息。

### 查看会话列表

直接发送消息（不带任何前缀），机器人会返回近期会话列表：

```
会话列表
发送 @会话ID <消息> 向会话发送消息：

/path/to/project
- @a1b2c3d4 修复登录Bug *
- @e5f67890 添加用户功能

/path/to/another
- @b3c4d5e6 代码重构
```

`*` 表示该会话正在运行中。

### 向会话发送消息

发送 `@会话ID 消息内容` 格式的消息即可向指定会话追加消息：

```
@a1b2c3d4 请继续修改
```

### 推送通知类型

| 事件 | 说明 |
|------|------|
| 会话已完成 | AI 会话执行完成，附带响应预览 |
| 会话已取消 | AI 会话被用户取消 |
| 操作需批准 | AI 请求执行需要审批的操作（如 Bash 命令、文件修改） |
| 定时任务已启动 | 定时任务开始执行 |
| 定时任务已完成 | 定时任务执行成功，附带响应预览 |
| 定时任务失败 | 定时任务执行失败 |
| 定时任务已取消 | 定时任务被取消 |

> 当有 WebSocket 客户端连接到 ClawBench（用户正在使用 Web 界面）时，推送通知会被自动抑制，避免重复提醒。

### 手动管理订阅

在 ClawBench 设置面板中可以查看和管理钉钉订阅者列表，支持手动添加和删除。

## 常见问题

**Q: 配置保存后没收到通知？**

A: 检查以下几点：
1. 应用是否已审核通过并发布
2. 事件接收方式是否选择了 Stream 推送
3. 用户是否在应用的可见范围内
4. 机器人是否开启了 Stream 消息接收模式

**Q: 测试连接成功但发消息没反应？**

A: 确认机器人已开启 Stream 消息接收模式，且事件订阅选择了 Stream 推送方式。

**Q: 推送模式如何切换？**

A: 在设置面板中选择不同的推送模式即可。钉钉和飞书互斥，切换后之前的订阅者数据不会丢失，切回来仍可使用。
