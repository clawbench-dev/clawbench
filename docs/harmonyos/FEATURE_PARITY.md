每项功能使用以下字段补充记录，可放在后续 `docs/acceptance/` 中：

```text
功能 ID / 子场景：
上游 commit / 安卓版本 / 服务端协议：
鸿蒙版本 / 构建 commit：
设备型号 / 系统 / API / ArkWeb 信息：
前置条件与脱敏测试数据：
操作步骤：
安卓预期：
鸿蒙实际：
通过 / 失败 / 受限 / 未测试：
截图或日志证据：
差异原因与后续动作：
```

含真实账户或私人内容的原始证据只留在忽略目录，入库前先脱敏。涉及删除文件、Git 写操作、任务触发等测试时，使用隔离测试数据。
