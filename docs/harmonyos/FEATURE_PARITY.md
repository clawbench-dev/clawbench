# 安卓与鸿蒙功能对齐清单

更新日期：2026-11-06

当前开发版 0.2.3 修复评审发现的凭据恢复、真实宿主桥契约、TLS 诊断与双语反馈，具体构建结果由维护记录保存。此前 0.2.0 至 0.2.2 在 HarmonyOS 7 / API 26 手机模拟器验证过部分文件、分享、剪贴板、选区、通知和媒体流程，以及 SSH / HTTP2 正反向数据转发；SSH 指纹确认和已有映射自动恢复有历史证据，录屏授权后仍挂起。没有任何条目通过真机完整验收，用户报告的后台消息问题仍待本轮修复后真机复测，单个子场景通过不等于整行功能通过。

鸿蒙实际：
通过 / 失败 / 受限 / 未测试：

含真实账户或私人内容的原始证据只留在忽略目录，入库前先脱敏。涉及删除文件、Git 写操作、任务触发等测试时，使用隔离测试数据。
