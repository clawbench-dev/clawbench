# 键盘快捷键参考（PC）

ClawBench 针对桌面端（PC，具备物理键盘）提供了一系列键盘快捷键。本文档按**界面 / 作用域**组织，说明每个快捷键在哪个界面、何种状态下生效。

> 约定：`Ctrl` 在 macOS 上通常对应 `Cmd`（⌘）。`Ctrl/Cmd` 表示 Windows/Linux 用 `Ctrl`，macOS 用 `Cmd`。
>
> 本指南面向 PC 场景；移动端无物理键盘，主要依赖触摸手势和虚拟按键栏，不在本文档范围内。

## 作用域说明

ClawBench 的快捷键大多采用**焦点感知**（focus-aware）设计：全局挂载的按键监听会检查当前焦点与激活面板，只有满足条件才触发，避免与输入框、终端等场景冲突。公共的屏蔽规则如下：

- **输入框 / 文本域 / 可编辑区域**：当焦点位于 `INPUT`、`TEXTAREA` 或 `contenteditable` 时，多数全局快捷键不生效（保留原生行为），仅输入框自身的快捷键有效。
- **终端面板**：焦点在终端（`.terminal-panel`）内时不触发聊天/文件类快捷键，避免与终端按键输入冲突。
- **对话框打开时**：模态对话框打开时，部分全局快捷键（如 Ctrl+F）被挂起。
- **Android App 模式**：部分桌面快捷键在 App 模式（`isAppMode`）下不生效。

## 全局搜索

作用域：**整个应用**（`App.vue` 的 `handleCtrlF`），焦点不在输入框/文本域/可编辑区域/终端，且无模态对话框打开时。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Ctrl/Cmd+F` | 打开上下文感知搜索抽屉 | 按当前**激活标签页**路由：聊天标签 → 会话搜索（RAG）；浏览标签 + 文件覆盖层 → 文件内容搜索；浏览标签无覆盖层 → 文件名搜索；已打开时聚焦输入框。宽屏双栏模式下按焦点所在的左侧/右侧面板路由。非可搜索标签页交给浏览器原生 Ctrl+F |

## 聊天面板

作用域：**聊天标签页**（`ChatPanelContent.vue`）。需满足焦点感知门控（`keyboardActive`），且焦点不在输入框/文本域/终端面板内。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Ctrl/Cmd+←` | 切换到上一个会话 | 聊天面板激活 |
| `Ctrl/Cmd+→` | 切换到下一个会话 | 聊天面板激活 |
| `Ctrl/Cmd+Delete` | 快捷归档当前会话 | 聊天面板激活 |

---

## 聊天输入框

作用域：**聊天输入框聚焦时**（`ChatInputBar.vue` 的 `onTextareaKeydown`）。这是输入框自身的快捷键。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Enter` | 发送当前消息 | 无 Shift/Ctrl/Cmd/Alt 修饰键 |
| `Escape` | 关闭 `@` 或 `/` 命令菜单 | 弹出菜单打开时（若同时打开，以 `/` 优先） |
| `ArrowUp` | 向上移动菜单高亮 | `@` 或 `/` 命令菜单打开时 |
| `ArrowDown` | 向下移动菜单高亮 | `@` 或 `/` 命令菜单打开时 |
| `Enter` | 选中当前高亮的菜单项 | `@` 或 `/` 命令菜单打开且已有高亮项 |

## 文件管理器

作用域：**文件浏览（browse）标签页**（`FileManagerContent.vue` 的 `handleKeydown`）。需满足：当前标签为 `browse`、焦点感知门控（`keyboardActive`，宽屏下要求左侧面板聚焦）、非 Android App 模式、焦点不在输入框/文本域。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Ctrl/Cmd+C` | 复制当前/多选文件 | 未选中文本（否则保留原生文本复制）；有选中或当前文件 |
| `Ctrl/Cmd+X` | 剪切当前/多选文件 | 同上 |
| `Ctrl/Cmd+V` | 粘贴剪贴板文件到当前目录 | 剪贴板有内容 |
| `Delete` | 删除当前/多选文件 | 有当前文件或处于多选 |
| `Shift+Delete` | 强制删除（跳过确认，不可恢复） | 有当前文件或处于多选 |
| `Ctrl/Cmd+A` | 全选 / 进入多选模式并全选 | 未处于多选时先进入多选 |
| `Enter` | 打开选中项（目录进入 / 文件预览） | 焦点不在按钮/链接上，且有选中项 |
| `Alt+ArrowUp` | 返回上级目录 | 始终 |
| `Backspace` | 返回上级目录 | 始终 |
| `F2` | 重命名选中项（或当前打开文件） | 有选中项或当前文件 |
| `Ctrl/Cmd+R` / `F5` | 刷新文件列表 | 始终 |
| `Ctrl/Cmd+Shift+H` | 切换隐藏文件显示 | 始终 |
| `Ctrl/Cmd+Shift+M` | 切换多选模式 | 始终 |
| `Space` | 切换选中项（多选时） | 处于多选且有选中项 |
| `Escape` | 退出多选模式 | 处于多选模式 |
| `ArrowUp` | 向上移动高亮选择 | 始终 |
| `ArrowDown` | 向下移动高亮选择 | 始终 |
| `Home` | 跳到列表顶部 | 始终 |
| `End` | 跳到列表底部 | 始终 |
| `Shift+ArrowUp/Down` | 移动并扩展多选范围 | 处于多选模式 |
| `Ctrl/Cmd+N` | 新建文件 | 始终 |
| `Ctrl/Cmd+Shift+N` | 新建文件夹 | 始终 |
| `Ctrl/Cmd+1` | 切换为列表视图 | 始终 |
| `Ctrl/Cmd+2` | 切换为网格视图 | 始终 |

## 代码编辑

作用域：**文件预览/编辑中的 CodeMirror 视图**（`CodeMirrorViewer.vue`）。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Ctrl/Cmd+S` | 保存当前文件 | 处于编辑模式、有未保存改动、且未在保存中 |

> CodeMirror 编辑器本身支持标准的编辑快捷键（复制/剪切/粘贴/撤销/重做/选择等），沿用浏览器与编辑器默认行为。

## 图片预览

作用域：**图片查看器聚焦时**（`ImagePreview.vue` 的 `handleKeyDown`，容器挂载后自动聚焦）。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `ArrowLeft` | 上一张图片 | 当前目录存在上一张图片 |
| `ArrowRight` | 下一张图片 | 当前目录存在下一张图片 |

## 通用弹层 / 对话框

作用域：**各类弹层、抽屉、对话框打开时**（`DialogOverlay.vue`、`BottomSheet.vue`、`PopupMenu.vue`、`ModalDialog.vue`、`ImagePreview` 灯箱等）。

| 快捷键 | 功能 | 生效条件 |
|--------|------|----------|
| `Escape` | 关闭弹层 / 取消对话框 / 退出多选 / 关闭菜单 | 弹层打开时 |
| `Enter` | 确认对话框 / 提交输入 | 对应输入或确认按钮聚焦时 |

> 对话框内部的输入框（密码、设置项等）支持 `Enter` 提交或跳转下一项，见 `PasswordChangeDialog.vue`、`SettingsItem.vue`、`CopyAgentDialog.vue` 等。

## 不在本列表中的常见操作

- **浏览器原生快捷键**（如 Ctrl+W 关闭标签等）由浏览器接管，未做拦截。
- **PPT / Excel / PDF 等文档预览**在桌面端支持鼠标滚轮缩放/翻页（如 PPT 的 `Ctrl+滚轮`），属于指针交互而非键盘快捷键。
- **终端**按键输入由 xterm.js 接管，其虚拟按键栏与手势见 [Web 终端使用指南](TERMINAL.md)。
