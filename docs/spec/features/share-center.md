# 分享中心

左栏「分享」页签：本项目已经发出去的**全部公开链接**，一条分享一行，加上「把它发出去 / 把它收回」两类动作。

## 为什么要有这一页

在它之前，三类分享各自长在不同的地方：

| 类型 | 创建 | 在哪管理 | 分享到别处 | 邮件 |
|---|---|---|---|---|
| 文件 / 文件夹 | 文件预览头部菜单、文件管理器右键 | 文件管理器工具栏的「已分享」抽屉 | 无 | 无 |
| 会话 | 会话行 `⋮`、聊天输入栏按钮 | 会话列表头的「已分享」抽屉 | 无 | 无 |
| 会议 / 听记 | 不用创建，开会就自动分配 token | **完全没有** | 无 | 无 |

四个问题：管理入口分散、会议根本没有管理入口、只有复制和打开页面（手机上想发微信得先复制再切应用再粘贴）、内置邮件客户端没有外部入口能带着链接进来。

**创建入口全部留在原地**。创建前得先选文件、勾消息，脱离上下文做不了；这一页只负责「已经发出去的这些，怎么发、怎么收」。

## 一行是什么

三类记录在三个表、三种形状里，各自已有自己的列表接口（文件→文件管理器、会话→会话列表、会议→会议面板）。**在客户端聚合**而不是加一个服务端联合接口：服务端不用改，且一行永远不会和它来的那个页面说法不一致。代价是每次刷新三个请求，所以只在打开时加载一次。

行内显示：类型图标、名称、类型名、次级信息（文件路径 / 消息数 / 会议时间）、分享时间，以及状态徽章：

- **文件已删除** —— 文件没了但链接还有效，行保留（否则这个链接再也撤不掉）
- **已归档** —— 会话归档，同上
- **会议进行中** —— 房间还在，链接此刻是「加入会议」的入口
- **仅自己可见** —— 会议已结束且没公开，链接只在会中有效

## 会议行的一条硬规则

**已结束、且没打开的分享开关的会议，不进这个列表。**

它的 token 在会议结束那一刻就 404 了（见[屏幕与声音共享](live-share.md)的「会议结束后的可见性是一个开关」）。把它列出来等于给用户一个打不开的链接。正在进行的会议则一定在：链接现在就能用，那是别人加入的方式。

会议行没有「关闭分享」意义上的删除——**链接就是记录本身**。行上的「关闭分享」发的是 `PATCH .../sessions/share {enabled:false}`（停止公开），不是 DELETE（那会连会议记录和产物一起删掉）。已结束的会议被停止公开后，行直接消失（它不再是分享了）。

## 动作

选中一行展开，先看到地址列表（沿用「本机全部地址」的实现，默认一条主链接），再看到动作条：

- **复制** / **打开**
- **分享到其他应用** —— 按宿主分派，见下
- **用邮件发送** —— 先试内置邮件客户端，再回退系统邮件，见下
- **关闭分享**

### 「分享到其他应用」按宿主分派

| 宿主 | 行为 | 按钮文案 |
|---|---|---|
| Android / HarmonyOS | 系统分享面板（`shareText`） | 分享到其他应用 |
| 桌面（Electron） | **复制到剪贴板** | 复制链接（桌面没有系统分享面板） |
| 浏览器 | `navigator.share`（需安全上下文），否则复制 | 有面板则「分享」，否则「复制」 |

桌面被**按宿主名排除**，不是探测 `shareText` 是否存在：桌面桥确实实现了这个方法，实现方式是写剪贴板。探测它会报告「有分享面板」，而那正是唯一没有面板的宿主。

用户在面板里取消分享（`AbortError`）**不算失败**，不会静默改成复制——他刚刚拒绝了分享，塞进剪贴板是个意外。

### 「用邮件发送」

1. **优先内置客户端**：先探一次 `GET /api/mail/accounts`。有邮箱 → 把「标题 + 正文（含链接）」停在一个模块级请求里，切到邮件页签，面板挂载/激活时消费它并打开写信页。收件人留空——只有用户知道链接要发给谁。
2. **没有邮箱 / 邮件功能被关 / 探测失败** → 打开系统邮件（`mailto:`），走 `openExternalUrl`（Android WebView 会吞掉 `window.open`，裸 anchor 在那里是死点击）。

**先探再切页签**，不是先切再发现没邮箱：后者会把用户扔在一个空的邮件页签里，而消息已经丢了。

## 清空

「清空」清掉本项目全部三类分享：文件与会话各发一个 `all:true` 的 DELETE，会议逐个 `PATCH enabled:false`（没有批量接口，且它们都走同一个 SQLite 写锁，并发只会排队）。**进行中的会议不参与清空**：它的链接还是别人加入的方式。
