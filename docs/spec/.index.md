# ClawBench 系统设计规格

> 本目录包含 ClawBench 系统的设计规格文档，由任务每日自动更新。
> 文档目标是帮助读者（开发者或 AI）快速建立对系统的心智模型。

## 目录结构

- [总览](README.md) — 系统定位、模块地图、文档导航

### core/ — 核心业务

- [聊天流程](core/chat-flow.md) — 用户发消息到 AI 回复的完整链路，含 ACP 权限审批、交互式提问卡（`<clawbench-ask-question>` → AskUserQuestion 工具调用，单选可取消，答案状态跨重渲染持久化）、/cb-* 内置命令注入、唯一 turn 实现与请求构造唯一实现、完成弹窗、未读自动清除、错误码透传、滚动保持机制、按项目恢复会话、输入草稿与会话快照恢复、多模式摘要（mixed/summary/original 消息展示模式）、DB 持久化消息队列（drain loop + 熔断 + 兜底回收器）、消息元信息区在气泡外、会话重置与消息回溯 Rewind（含清空计划面板）、ACP _meta 用量明细展示（最新完整快照）、子智能体内容分组（按 _meta 父工具调用 id 折叠进父 Agent 卡片）
- [AI 后端抽象](core/ai-backend.md) — 双传输后端（CLI + ACP stdio）、acpStdoutFilter 协议修复、CodeWhale ACP 字段重映射、BackendRegistry、共享规则模板、CodeBuddy skills 扫描、ACP `_meta` 扩展元信息解析、子智能体父工具调用归属（parent linkage）
- [流式传输体系](core/streaming.md) — 统一 WebSocket StreamHub + 断线缓冲重放 + 投递可观测（delivery-stats）+ 关键事件等待/增量丢弃双层分级 + 前端有界缓冲回放 + 旁注小 SSE/WS 通道（file_watch/dir_search/tts_audio）
- [会话生命周期](core/session-lifecycle.md) — 创建、执行、取消、设置即时持久化、归档、单一 owner runner（运行态与可取消性同源）、唯一 turn 实现与队列兜底回收
- [摘要管线](core/summarization.md) — 双管线（TTS vs 阅读摘要）、多 pass 压缩、Block 提取算法、降级链

### features/ — 功能特性

- [首次访问欢迎面板](features/setup-wizard.md) — WelcomeOverlay 后端检测面板（非分步向导）；Agent 走自动发现 + AgentInstallDialog
- [任务](features/scheduled-tasks.md) — cron 调度到 AI 执行到摘要推送，ACP 自动审批，事件触发任务（GitHub/GitLab 事件唤起，列表行与聊天预览卡均展示订阅事件），执行级逐条已读，执行详情固定摘要/原文 tab
- [Forge 集成](features/forge-integration.md) — GitHub/GitLab Issue + PR/MR 只读浏览、面板内「动态」页签（未读/已读/全部）、后台轮询感知、CI 完成事件、流水线 ↔ PR 双向跳转、按条目未读与通知、事件触发 AI 任务、URL 附件、自部署实例 http/https
- [语音合成](features/tts.md) — 引擎选择、文本清理、缓存策略
- [Web 终端](features/terminal.md) — 多标签 PTY 会话、虚拟键盘、键位配置、TUI 支持
- [Git 管理](features/git-management.md) — 历史浏览（工作区变更页按需重拉）、Worktree、分支、标签、代码量统计（存量 cloc 按 .gitignore 排除 + 增量 git stats 双子页）、停靠页与抽屉共享同一套视图逻辑
- [文件管理](features/file-management.md) — 浏览+覆盖层预览（按 .gitignore 灰显忽略条目）、二进制文件处理、符号提取、Markdown HTML 导出（共享渲染管线）、代码链接预览（代码切片浮层卡片，设置开关默认关）、文件分享链接（capability token + 创建时根快照边界）、上传、归档
- [文件发现](features/file-discovery.md) — 搜索融合进文件管理器（内嵌视图 + 结果复用条目交互与忽略灰显）、结果展示所在目录、全局蕴含递归、Shift 范围选、最近文件、统一覆盖层打开
- [附件与系统分享](features/attachments-and-share.md) — 上传历史、Share In、多文件附件
- [会话导航与分叉](features/session-navigation.md) — 用户消息索引（含搜索即时过滤与命中高亮）、跨分页定位、会话分支、分叉上下文预算压缩（优先保留全部用户消息）
- [会话标签](features/session-tags.md) — 按项目隔离的标签定义与关联、长按菜单打标签、标签行、顶部过滤栏（可换行 + 高度封顶）、可读性校准的哈希配色、胶囊即选中控件、失败可见、全量替换语义
- [快捷操作](features/quick-actions.md) — 聊天快捷发送、终端快捷命令、排序与持久化
- [智能体用量统计](features/usage-stats.md) — 按项目聚合 chat_metadata 独立用量台账：用量总览环形图 + 缓存命中下钻、按指标拆分的图表（bar/pie/trend 可切换）、时间窗与维度筛选、费用两位小数统一；数据统计页签另含代码存量/代码增量子页
- [RAG 检索](features/rag.md) — 文档索引、向量化、搜索、会话聚合搜索（match_positions 高亮）、可配置批次大小、索引磁盘占用、独立 FTS 重建
- [推送通知](features/push-notifications.md) — 权限待审推送、WebSocket 实时推送、钉钉企业机器人 Stream API + Markdown 单聊
- [应用内完成通知](features/completion-popup.md) — 后台事件时滑入纯通知卡片：类别 chip + 事件类型 chip（语义配色）+ 主体名称 + 最多 4 行摘要 + 跨项目换色区隔带 + 跳转（顺带标记已读）+ 关闭，5 秒自动关闭；覆盖会话/任务/仓库，与系统通知对齐

### infra/ — 基础设施

- [认证与中间件](infra/auth-and-middleware.md) — 密码认证、本机 AI 短时令牌、隧道信任边界限制、按路由认证、请求链
- [SSH 隧道](infra/ssh-tunnel.md) — direct-tcpip、端口映射、端口白名单默认 1024-65535（ISS-186）、端点按受众拆分（`/api/ssh/info` 公开最小 / `/full` 需鉴权）
- [FRP 隧道](infra/frp-tunnel.md) — 进程内 FRP 客户端、状态机、热重载 vs 重启、自动端口、WS 事件广播、双认证 API
- [Proxy 注册表](infra/proxy.md) — 端口管理、路由、前端展示
- [配置与自动发现](infra/config-and-discovery.md) — 零配置启动、DB-backed Agent、双传输、Model 发现、多实例 Cookie 隔离、Schema 迁移、覆盖率门禁
- [事件体系](infra/event-system.md) — WebSocket Manager / StreamHub、ACP 状态重发、缓冲重放（≤10s / ≤50 条）、订阅超时清理（>120s）、投递丢弃计数与关键事件可靠投递
- [应用自升级](infra/self-upgrade.md) — 版本检查、安装目录可写预检、备份替换、进度事件、重启恢复、容器内就地替换
- [本地文件服务](infra/local-file-serving.md) — 文件 URL、媒体响应、下载与路径安全
- [Docker 部署](infra/docker-deployment.md) — 单阶段运行时镜像、数据卷持久化、GHCR 发布、容器升级策略
- [CLI 子命令](infra/cli-reference.md) — 仅剩 upgrade-replace（自升级内部机制）；业务子命令 task/rag 已移除，改由内置斜杠命令直调 HTTP API
- [Bugfix 工作流](infra/bugfix-workflow.md) — 自动化 bugfix 生命周期、标签体系、worktree 隔离、测试要求、PR+CI 流程

### client/ — 客户端

- [统一返回与跨界面导航](client/unified-back-navigation.md) — 两级分层栈（文件历史 + jump origin）、返回状态机优先级、目录游历事务、滚动位置还原、双击退出、多端返回入口（桌面顶栏簇/移动底部胶囊/手势/物理键）
- [前端架构](client/frontend-architecture.md) — 单页布局、ACP 会话管理、composable 模式、统一 WS StreamHub、appLog 强制日志、统一返回状态机、代码链接预览（useCodeLinkPreview 单例状态机 + CodeLinkPreview 浮层/底部抽屉）、FileHeader 三层弹性布局、36 命名主题系统（快捷选择器 + 外观深链 + 实时跟随系统 + 自定义字体双通道 + 自定义壁纸背景）、统一搜索控件（SearchBar）、TOC 停靠栏、Markdown 共享渲染管线（useMarkdownRenderPipeline + mediaBlockFactory 统一内联媒体 figure）、Excalidraw 画布编辑、历史加载 DB 权威重建（含陈旧快照下保留活跃占位符）、会话重置、完成弹窗、宽屏聊天区切换、Dock 数据统计页签（用量/代码存量/代码增量三子页）、统一刷新按钮、会话列表扁平化、Git 历史视图共享逻辑（useGitHistoryView）、Android 输入恢复、计数角标统一（.count-badge）
- [Android 集成](client/android-integration.md) — JS Bridge（25+ 方法）、12 个 Java 模块（含桌面悬浮状态窗 + 会话面板 + Live Updates 实时更新）、Android 全量国际化、APK 嵌入（`build.sh --android`）、AppLog 统一日志、WS 优先 + Worker 回退
- [多服务器管理](client/multi-server.md) — 服务器列表、凭据持久化、快速切换
- [客户端安装与 App 模式](client/install-and-app-mode.md) — PWA、iOS 安装指引、APK 与原生模式
