功能

不是一个聊天框，
是一整套工作流。

从读文件到提交代码，从定时任务到公网访问——原本需要在终端里敲命令的事，都在同一块界面里完成。

AI 对话

流式输出、工具调用可视化、思维过程可见、交互式提问卡，以及会话内的运行中插话。

多智能体群聊

把多个后端拉进一个群，主持人模式轮流发言，或自由模式用 @ 接力。可开自动巡航跑到任务完成。

文件管理

递归浏览、按 .gitignore 灰显、多选批量操作、拖放移动、目录树下载与文件分享链接。

代码编辑

CodeMirror 浏览与编辑双模式，语法高亮覆盖 170+ 种语言，长尾语言按需懒加载，首屏不为它付费。

Markdown 与图表

LaTeX 公式、Mermaid 图表、目录抽屉、代码链接预览，以及自包含的 HTML 导出。

文档与媒体

Word、Excel、PowerPoint 原生渲染，PDF 分页缩放，图片、音频、视频内联播放与灯箱放大。

Git 与 Forge

提交历史、分支图、Diff 视图与工作树管理；GitHub / GitLab 的议题、合并与流水线可以直接引用进对话。

Web 终端

基于 PTY 的多标签终端，三模式手势系统、虚拟修饰键、157 个终端主题，手机上也能用 vim。

定时与事件任务

Cron 定时或 Git 事件触发，可选前置脚本：脚本静默成功就跳过本次 AI，也不发通知。

SSH 与端口映射

正向与反向端口映射，全协议透明（HTTP / WS / SSE / gRPC），也可以在手机上直连家里的 localhost。

通知与推送

通知中心汇总会话、任务与仓库事件；同时支持钉钉、飞书机器人，在 IM 里查看会话并回消息。

主题与壁纸

36 个命名主题、跟随系统切换、圆形扩散动效；本地图库、Bing 每日与动态壁纸三种来源。

部署

一条命令，
六十秒跑起来。

不需要 Node 运行时，不需要额外的数据库服务。首次启动会生成随机密码并打印到控制台。

bash
# 国内用户建议先走镜像，秒下
npm config set registry https://registry.npmmirror.com/
npm install -g @xulongzhe/clawbench
clawbench
docker
docker pull ghcr.io/clawbench-dev/clawbench:latest
docker run -d --restart unless-stopped \
  -p 20000:20000 \
  -v clawbench-data:/data \
  ghcr.io/clawbench-dev/clawbench:latest
bash
# 从 Releases 下载对应平台的压缩包，解压即用
TAG=$(curl -sI https://github.com/clawbench-dev/clawbench/releases/latest \
  | grep -i '^location:' | sed 's|.*/tag/||' | tr -d '\r\n')
wget "https://github.com/clawbench-dev/clawbench/releases/download/${TAG}/clawbench-linux-amd64-${TAG}.zip"
unzip "clawbench-linux-amd64-${TAG}.zip" && cd clawbench && ./clawbench

部署完成后，用手机 App 或任意浏览器访问 http://服务器IP:20000 即可开始使用。

常见问题

你可能想先问清楚的事。

开始之前需要准备什么？

一台能运行 AI 编程智能体 CLI 的机器（Linux / macOS / Windows，或装了 Termux 的安卓手机），以及至少装好其中一个智能体。然后在同一台机器上运行 ClawBench，用任意浏览器访问它的地址即可。

真的能在手机上完整运行吗？

可以。后端是纯 Go 的 linux-arm64 静态二进制，前端已经内嵌，通过 Termux 的 npm 安装后直接运行——AI 智能体也在手机本地执行，不需要额外的 PC 或服务器。

数据存在哪里？会不会被上传？

全部落在你自己的机器上：一个 SQLite 数据库加上数据目录里的文件，没有第三方中转。密码用 SHA-256 加盐存储，本机请求也要带 HMAC 短时令牌。想从公网访问时，建议配合隧道或反向代理并启用 TLS。

支持哪些 AI 智能体？

内置 19 个后端：CodeBuddy、Claude Code、OpenCode、Codex、Qoder CLI、VeCLI、CodeWhale、DeepSeek Harness、MiMo-Code、Pi、Copilot、Kimi、Antigravity、Grok Build、ZCode、Cursor、Hermes Agent、Command Code、OpenClaw。另外可以添加自定义 ACP 智能体——任何以 stdio 说 ACP 的工具，填一条启动命令就能接入。

在外面怎么访问家里的机器？

支持 IPv6 直连、EasyTier 去中心化组网（不需要 VPS）、SSH 隧道以及 HTTP/2 流隧道。反向映射只绑 127.0.0.1 并禁用保留端口，避免把不该暴露的服务带出去。

收费吗？

ClawBench 本身是 MIT 许可的开源软件，不收费。你自己在用的智能体（及其订阅或 API 计费）另算，费用归各自的提供方。
